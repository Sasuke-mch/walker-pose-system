# Walker experiment records

`research_records` is the authoritative location for research evidence.

- `official_runs`: cite only after an experiment card is complete.
- `screening`: informative model/configuration comparisons, not performance claims.
- `engineering_validation`: implementation and pipeline milestones.
- `retired`: no longer active and must not be used as evidence without revalidation.

Never delete a raw capture independently of its AVI files, frame CSV files, pair CSV file, and capture metadata.
Every future formal run needs a completed experiment card and a code snapshot or a clean Git commit.
