# 接触状态与地面一致性推进记录

日期：2026-09-30  
阶段：接触模型阶段 1（接触状态与坐标诊断）  
状态：已实现、已通过单元测试；尚未接入 SMPL 拟合，不代表真实触地或握持。

## 1. 本阶段目标

本阶段只解决“当前帧是否具备进入接触约束的工程证据”。输入是表面几何和跨帧运动诊断，输出是带拒绝原因的候选状态。阶段不修改人体姿态、根部平移、SMPL beta 或三角化结果，也不把候选状态写成物理真值。

状态定义为：

| 状态 | 含义 | 后续允许的用途 |
|---|---|---|
| `unknown` | 观测非有限、质量不足或地面变换不连续 | 不启用接触约束 |
| `separated` | 距离超过退出门 | 不启用接触吸引 |
| `contact_candidate` | 接近接触区域，但时间或运动证据不足 | 只作诊断 |
| `sticking_candidate` | 接近且切向速度小 | 可进入条件防滑消融 |
| `sliding_candidate` | 接近但切向速度较大 | 只启用距离/非穿透，不能启用零速度项 |

## 2. 实现文件

- `realtime_app/pose_app/contact_state.py`
- `realtime_app/tests/test_contact_state.py`

`ContactObservation` 使用秒、米和米/秒作为单位，避免把固定帧数误当成时间。字段包括：

- `timestamp_s`：采集时间；
- `distance_m`：表面区域到参考对象的距离；脚部使用地面高度，手部应使用握把表面距离；
- `normal_speed_mps`：沿接触法向的速度；
- `tangent_speed_mps`：接触切平面内的速度；
- `quality`：上游几何质量，仍受严格观测门约束；
- `ground_continuous`：地面变换是否与上一可用帧连续；
- `finite`：输入是否有限。

## 3. 滞回状态机

默认工程门为：

```text
进入距离：15 mm
退出距离：25 mm
进入法向速度：80 mm/s
黏着切向速度：60 mm/s
滑动切向速度：120 mm/s
进入持续时间：80 ms
退出持续时间：100 ms
最低质量：0.25
地面位姿跳变上限：60 mm（由上游连续性诊断提供）
```

进入和退出距离不相同，避免噪声造成单帧抖动。状态机按时间戳累计持续时间：即使视频帧率改变，80 ms 的含义仍一致。观测质量不足、输入非有限或地面变换断裂时立即转为 `unknown`，不会沿用上一帧的接触状态。

状态机只输出 `ContactDecision`，其中保存状态、是否允许后续约束、原因、原始诊断量和来源字符串。`accepted_for_constraint=true` 只表示满足当前工程门，不表示物理接触已经被测量确认。

## 4. 脚底分区诊断

`surface_partition_metrics()` 接收固定 SMPL 表面索引和地面坐标系下的顶点，逐区输出：

- 有效点数量；
- 最低高度；
- 中位高度；
- 穿透比例；
- 空索引、越界索引和非有限区域的 `available=0`。

该函数不取最低点补全、不插值、不平滑，允许后续分别统计 heel、ball、toe。只有一个最低点接近地面不能说明整只脚接触；后续阶段应同时使用接触区域覆盖率、最低高度和固定表面点的相对速度。

## 5. 当前未实现的部分

本阶段暂不实现以下内容：

1. 脚底非穿透损失和接触吸引损失接入拟合；
2. 同一表面点的切向速度损失；
3. 握把坐标系下的手部相对速度；
4. 支撑多边形或质心硬约束；
5. 摩擦锥、接触力或承重估计。

其中第 4 项不能直接作为行走硬约束；第 5 项在没有力传感器时只能作为假设下的可行性分析，不能称为测得的力。
