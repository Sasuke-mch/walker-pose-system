## 2. 要解决的任务是什么

我们已有双目观测和一个初始化人体。现在又给定助步器上的左右抓握目标，希望人体调整身体姿态，让腕部接近目标，同时保留观测支持的身体位置，避免脚和手的几何变坏。

把人体想成一个有关节的三维模型，但程序不能直接随意拖动每一个网格顶点。它调整少量参数，然后通过模型重新生成关节和表面。

记第 t 帧的身体变量为 x_t：

- `z_t`：32 维 VPoser 潜变量，可以理解为身体姿态的 32 个控制量；没有一维只代表一个关节的保证。
- `r_t`：根部旋转增量，3 维。
- `q_t`：根部平移增量，3 维，单位米。
- 左右手各 12 维的共享 MANO PCA 系数：只在最后手部阶段释放，同一只手在窗口内共享一组系数。

VPoser 将 z_t 解码为 21 个身体关节的旋转；SMPL-H 根据身体、根部、固定体型和手参数生成 6890 个顶点。不能在解码后直接把腕旋转覆盖成目标，否则绕开了身体参数化。

这里使用的是当前固定抓握实验中的 SMPL-H 分支，不应把它的结论泛化为仓库全部 SMPL/SMPL-X 路线。

## 4. 软目标与硬保护：这是理解方法的关键

总损失 L 是多个惩罚项的加权和。它包含身体三维/二维观测、腕位置/朝向/越界项、姿态与根部先验、时序项、脚表面项、Stage2 脚锚和手表面几何项。

软目标允许互相交换。例如腕改善带来的收益大于腿项增加的代价，总损失仍可下降。

硬保护则不同：触发后，即使总损失下降，这一步也不能提交。

### 4.1 不可变观测保护

设当前第 t 帧第 j 个模型 COCO 点为 P_tj(x)，三角化观测为 Y_tj，原始参考误差为 e0_tj：

```text
e_tj(x) = ||P_tj(x) - Y_tj||
c_tj(x) = e_tj(x) - e0_tj - 0.010 - 0.000001
要求 c_tj(x) <= 0
```

其中 10 mm 是原允许退化量，1 微米是既有数值容差。保护每一个已接受的三角化点，而不是只保护平均误差；低质量点只影响损失权重，不能据此静默移出保护集合。未接受点不作为有效观测约束。

例如某点原误差 30 mm，本次不能借助手腕改善把它推到 50 mm。上一轮走到 39 mm，也不能把下一轮预算更新成 49 mm。

### 4.2 上肢阶段额外保护

`upper_only` 阶段还要求 COCO 的髋、膝、踝六点相对原始参考的位移不超过 5 mm，另加原数值容差。这里比较的是点位置移动，不是相对观测误差。

阶段名容易误导：该阶段只释放 latent，但 latent 仍实时解码全身。它没有把腿关节从计算图中切掉，腿保护因而不可省略。

### 4.3 单步接受与最后验收不同

每步还检查手 PCA 相对构造参考的逐系数偏移不超过 2、参数实际发生变化、损失有限且不高于本步原损失加 1e-6。

**目前脚不恶化、每个身体组不恶化、腿时序不恶化，并没有全部成为单步硬保护。** 它们有软损失和最终验收，但中途仍可能退化。这是当前方法的重要边界。

## 5. 为什么普通 Adam 回退会卡住

Adam 根据梯度与历史一、二阶矩提出参数增量。原方法先试整步，失败就尝试 1/2、1/4，直到 1/128，共 8 次。一个关键点越过保护边界，会使整窗候选被拒绝。

考虑二维示意：可行区域为 `a <= 0`，当前在 `(0, 0)`，Adam 想走 `(1, -1)`。任何正比例缩小仍有 `a > 0`，所以方向不变的缩步一直越界。然而 `(0, -1)` 完全可以沿边界前进。

这说明“Adam 没走动”不等于“没有可行方向”。投影的目的，就是尽量去掉越界方向分量，保留其余移动。

## 6. 第一步：归一化 Adam 增量

核心函数：`realtime_app/pose_app/constrained_grasp.py::constrained_adam_step`。

先保存旧参数和完整 Adam 状态，再调用一次 `optimizer.step()` 得到候选增量 d_A。不同变量单位不同，先用尺度 S 归一化：

```text
u_A = S^(-1) d_A
S: latent 1，根旋转 1 rad，平移 0.05 m
每帧 ||u_A||_2 <= 0.2，超出则按比例缩小
```

0.2 是所有已释放参数共同占用的归一化半径，不能解释成每一个变量都可独立用满额度。若只平移，半径对应最多 10 mm；若还改变姿态，平移可用额度会更少。

固定半径用于限制局部线性近似的使用范围。代码没有依据预测/实际下降比自适应调整半径，不能称为完整信赖域算法。

## 7. 第二步：线性约束投影

在旧参数 x 处，把约束局部近似为：

```text
c(x + S u) ≈ c(x) + J(x) S u
A = J(x) S
b = -c(x)
```

J 是雅可比矩阵：每一行描述一个约束对各参数的敏感程度。比如某行可以理解为“身体参数各动一点，这个右肘的保护余量会怎样变化”。

每帧解一个小问题：

```text
最小化  0.5 * ||u - u_A||²
约束    A u <= b
```

它追求的是“在局部约束内尽量接近 Adam 提议的步子”，不是直接求全身损失的全局最小值。欧氏距离是在归一化坐标中度量，因此参数尺度也是方法的一部分。

实际求解在 `project_halfspaces`：约束行做范数归一化，使用非负对偶变量 lambda，通过 L-BFGS-B 求解：

```text
最小化  0.5 * lambda^T A A^T lambda - (A u_A - b)^T lambda
约束    lambda >= 0
恢复    u = u_A - A^T lambda
```

这里的 A、b 指行归一化后的矩阵。使用 float64，最大迭代 1000；线性可行认证看归一化后的最大违反量是否不超过 1e-7。这个数不是可以直接换算成米的原始观测误差容差。

`solver_success=True` 不能替代认证。当前 `passed` 只表示线性可行残差满足要求，没有完整认证投影最优性、互补性和原问题 KKT 条件。

只有原提案越界，或旧状态距离任一约束边界不足约 0.5 mm 时，代码才需要启动投影。任何帧未获得所需认证，该次候选就拒绝，不把它写成“人体目标不可能实现”。

## 8. 第三步：为什么还要非线性修正

线性近似把弯曲边界看成局部平面。沿平面可行，不保证真实模型更新后可行。

一个直观例子：可行区域是单位圆盘 `a²+b² <= 1`，起点 `(1,0)`。切向增量 `(0,h)` 满足一阶条件，但真实新点 `(1,h)` 在圆外。任何非零 h 都有二阶越界；若沿曲面向内补一点，才可能前进。

corrected 在真实候选 x_trial 越界时重新计算 J，而不是一直沿同一条方向缩步。每次修正求最小范数位移 v：

```text
最小化  0.5 * ||v||²
约束    J(x_trial) S v <= -c(x_trial) - 1e-7
更新    x_trial <- x_trial + S v
```

这里 1e-7 是原始约束值中的 0.1 微米向内目标，不是放宽观测预算；它与前节行归一化线性残差阈值含义不同。

每个缩步比例最多做 4 次恢复。恢复后相对事务起点的总归一化增量仍不得超过每帧 0.2，不能每修正一次就重新获得一份半径。

每次实际应用修正，都重新运行真实 forward，检查完整损失和原保护。若修正 QP 未认证，或者总位移超过半径，则记录原因，转入更小的原始方向候选。

**恢复只处理 `local_constraints` 中的观测及上肢腿位移约束。** 如果候选已满足保护，只是目标不下降，当前恢复循环会停止；它不会自动寻找另一个更好的目标下降方向。

## 9. 第四步：整窗验收与完整回滚

伪代码概括如下；它用于解释，不替代源代码：

```python
old_x = snapshot_parameters()
old_adam = deepcopy(optimizer.state_dict())
committed = False
try:
    proposed_step = adam_proposal()
    direction = normalized_projected_direction(proposed_step)
    if not direction.certified:
        return reject("linear_projection_not_certified")
    for alpha in [1, .5, .25, .125, .0625, .03125, .015625, .0078125]:
        x = old_x + alpha * direction.actual_parameter_step
        loss, guards = exact_forward_and_guards(x)
        for _ in range(4):
            if guards.pass_all or not repairable_local_violation(x):
                break
            repair = relinearized_minimum_norm_repair(x)
            if not repair.certified or exceeds_total_radius(old_x, x, repair):
                break
            x += repair.step
            loss, guards = exact_forward_and_guards(x)
        if changed(x, old_x) and guards.pass_all and finite(loss) and loss <= old_loss + 1e-6:
            committed = True
            return accept(x)
    return reject("no_accepted_trial")
finally:
    if not committed:
        restore_parameters(old_x)
        optimizer.load_state_dict(old_adam)
```

回滚 Adam 状态很重要：Adam 有历史记忆，不能只把人体恢复原位，却让拒绝过的步骤继续影响下一步矩估计。

接受投影/修正步时，当前实现保留 Adam 原提案产生的矩。实际提交步与原提案不完全一致，这是已知启发式；不能据此宣称标准 Adam 或完整 SQP 的收敛保证。

逐帧投影只用于构造候选。时序损失把不同帧联系起来，所以最后必须对整窗统一检查损失，不能每帧挑最有利结果再拼起来。

`frame_local_jacobian` 利用“约束只依赖本帧参数”计算逐帧雅可比。将速度、加速度或跨帧共享手参数约束直接塞进这个函数，会破坏这一假设；后续扩展必须改雅可比结构，不能只增加一行损失。

## 10. 四个优化阶段

| 阶段 | 释放变量 | 特点 |
|---|---|---|
| `upper_only` | 每帧 latent | 根部与手 PCA 固定；六个腿点 5 mm 位移门；腕相关三项共同渐进激活 |

## 11. A 的只读方向探针能证明什么

`probe_local_goal_descent` 使用双腕平方距离和的负梯度，按每帧半径 0.02 归一化，再投影到原局部约束内，执行最多 8 次真实缩步。

成功意味着：在该状态、选定参数块和这条搜索路径上，存在一个实际参数变化，满足探针所检查的观测/上肢腿保护，并使双腕平方距离总和下降。记录同时保存左右两侧各自的全窗变化。

注意实现的成功条件是两侧总和下降，不是强制两侧分别下降，更不是每帧每侧都下降。某次输出若两侧都下降，可以对那次实际输出这样描述，不能提升为函数通用保证。

探针不认证脚、完整损失、最终 10 mm 腕门，也不证明全局可达。失败只说明本次未找到合格见证。

探针结束恢复参数值；但 PyTorch 参数版本计数已改变，旧计算图不能接着求导。当前调用在初始梯度审计完成并丢弃旧图后进行，避免历史启动失败。

## 13. 为什么优先重新检查目标设计

当前腕软界为：

```text
r = relu(wrist_distance - 0.010) / 0.001
L_bound = 10 * (mean(r²) + max(r²))
```

另有权重 20 的腕位置项，以 5 mm 归一化。阶段腕倍率同时作用于位置、旋转和软界。

若腕距离 100 mm，单个软界平方残差为 `(90/1)² = 8100`，尚未乘权重和组合统计。大的腕残差可能使其他软目标被交换掉。损失数值大不自动等于梯度大，需要同时检查加权梯度及真实步后的各项变化。

60 窗 corrected 没有初始投影未认证，却有 91 次末次候选满足所记录保护而未接受；不能把这里的停滞全部归咎于 QP。现有计数本身也不严格证明 91 次全是目标上升，仍需逐条区分目标、实际变化与有限性原因。

## 14. 拟议阶段一：兼容性诊断的实现设计

验证目标：确定当前腕目标、观测保护、地面和脚锚有没有明显的语义/几何/时序冲突。固定输入，不修改目标求通过。

建议逐 `pair_id`、左右侧输出以下字段到新诊断结果，保留 unknown/unavailable：

1. 腕原生关节与 COCO 腕的位置差；腕目标位置误差及 SO(3) 朝向角误差；左右手映射与坐标变换往返误差。
2. 肩到目标距离、上臂/前臂长度、二连杆内外界超出量；活动观测约束、局部方向导数和实际有限步变化。
3. 脚候选状态来源、Stage2 段身份、有效帧、地面变换来源和是否冻结复用。
4. 固定 heel/ball 顶点相对脚锚的位置/高度/速度残差，以及建锚时主动抬升量。
5. 静止假设和原观测运动是否冲突；无法由现有观测判断时明确写“没有独立依据”，不自动转成静止标签。

Stage2 当前在不可变完整参考序列先建锚：每脚 heel/ball 各 3 个固定顶点，XY 使用段内参考中位数，并将每脚整体 Z 按参考鞋底高度移到地面。它是工程设计目标，不是测量到的脚接触。

建议实现先复用现有 `build_stage2_anchors`、`stage2_terms` 和已保存冻结状态，只补诊断；不要另写一套脚顶点或坐标规则。若诊断发现输入身份、坐标或覆盖错误，先单独修复并验证。若只是多目标冲突，记录冲突，进入预注册消融，不擅自移动目标。

完成标准是诊断可追溯和冲突/未知状态明确，不是强行给出“全局可行”。

## 15. 拟议阶段二：1 mm 对 5 mm 软界尺度实验

### 15.1 最小代码改动设计，尚未实现

在 `refine_body_with_constructed_grasp.py` 增加例如 `--wrist-bound-scale-m`，默认 0.001；校验有限且大于零，写入运行元数据。仅将腕软界两处分母 `.001` 替换为该参数：

```python
# 拟议代码，当前仓库尚未有此参数
scale = args.wrist_bound_scale_m

```

默认值必须复现旧公式。不得顺带修改 10 mm 腕目标边界、腕位置项的 5 mm 尺度、权重 10/20、激活倍率、步数或保护门。

### 15.2 对照设计

| 项目 | 设置 |
|---|---|
| 优化器 | 两组均 corrected，恢复次数 4 |
| 唯一变量 | 软界归一化尺度：0.001 m 对 0.005 m |

| 窗口 | 270–295、60–100，失败帧全部保留 |

最好在同一最终代码版本下重跑 corrected 的 1 mm 对照，避免把实现版本差异混入尺度效果；旧 v3 作为历史一致性检查。Adam 仍可保留作参照，但“尺度效果”的直接比较是 corrected 1 mm 与 corrected 5 mm。

不同尺度下总损失单位权重已变，不能比较两组总损失大小来判优。比较原始毫米、角度、各身体组、脚表面、腿时序和完整手几何。

建议新协议预先规定判读：所有原保护及覆盖必须通过；再检查双腕 P95、每个身体组、双脚和腿项是否在预定数值容差内均不恶化，并要求至少一个任务指标有超出预定容差的改善。若出现取舍，结论写“权衡改变”，不能写“整体胜出”。即使候选相对更好，原五门任一失败仍不得升级主拟合。具体比较容差须在运行前冻结，不能看到结果后选择。

### 15.3 所需验证

- 默认 0.001 下项值与梯度和旧公式一致。
- 相同输入改为 0.005 时，软界项值及梯度为旧值 1/25；其他项不随参数改变。
- 非法尺度 NaN、无穷、零、负数必须拒绝。
- 元数据、命令、协议与独立审计能还原尺度；输入、预算、帧范围和手覆盖不变。
- 保留所有拒绝原因；若发生坐标/覆盖/非有限错误，停止并保留失败证据。

完成尺度实验后，才考虑另一项独立的激活调度实验。当前上肢阶段已有 ramp，不能把它描述为首次引入渐进激活。

## 16. 拟议阶段三：根据失败类型继续改优化器

| 失败类型 | 应检查的内容 | 不能作出的结论 |
|---|---|---|
| 线性投影未认证 | 行缩放、秩、对偶残差、近退化约束、停止准则 | 人体目标全局不可达 |
| 线性可行但真实越界 | 边界曲率、修正次数、总半径 | 删除阻断观测即可解决 |
| 原保护可行但未接受 | 原/新目标、各项变化、实际参数变化、有限性 | 继续增加恢复次数一定有效 |
| 单步持续接受但最终质量失败 | 目标权衡、脚锚依据、腕朝向、验收指标 | 接受率高所以算法已成功 |

下一步日志可补 `before_loss`、`after_loss`、加权分项变化、`changed`、明确拒绝类别和两侧/逐帧腕变化。先只增加诊断验证行为不变，再单独改变算法。

若有充分证据需要分层保护，可设计“先满足可信观测与身体预算，再在剩余空间改善腕”的策略。但不能直接把所有软项改成每一步不得变差：这会阻断必要的暂时调整，也可能使初始状态不可行。当前脚底已经显著低于最终 -3 mm 门，需要有记录的恢复阶段与最终门，不能靠放宽最终门解决。

跨帧时序和共享手参数需要耦合优化结构；它们不能沿用本帧独立雅可比捷径。完整 SQP、自适应信赖域或分层优化都属于后续方案，当前 corrected 没有实现这些完整算法。

## 18. 研究依据与结论边界

- [SciPy trust-constr 官方说明](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-trustconstr.html)：约束违反和最优性分开检查，自适应信赖域与目标/约束平衡具有明确算法含义。本文用它解释当前实现尚缺哪些认证，不表示当前程序调用了 trust-constr；当前投影求解器使用 L-BFGS-B。
- [PROX，ICCV 2019](https://arxiv.org/abs/1908.06963)：利用三维场景中的接触和非穿透改善人体拟合。这支持接触几何的重要性，但不能证明本项目工程地面、静止标签与构造抓握目标正确。

当前所有结果是固定输入下的工程优化与内部一致性证据，没有独立三维/物理接触真值。最值得保留的是“利用约束信息改变方向并修复非线性越界”这一机制；下一阶段要验证的是它所追逐的目标是否合理、各目标的相对作用是否合适。
