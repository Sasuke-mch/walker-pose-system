## 3. 当前完整数据处理流程

### 3.1 图像、观测与相机坐标

物理身份用 PnP `instance_id` 注册表解析；不能用 Windows OpenCV 数字索引代替永久身份。标定角色固定 `cam0=LEFT`、`cam1=RIGHT`。

二维模型可在转正图像上运行，但进入几何前必须逆旋转回原始1920×1080鱼眼像素。当前转正图像为1080×1920。左图 CCW90 的逆变换为 `x=1919-v, y=u`；右图 CW90 的逆变换为 `x=v, y=1079-u`。边界状态、置信度、帧对应关系和不可用点继续保存。

场景严格三角化沿用原质量门、`max_matches=1` 和逐点拒绝原因。另有身体拟合的原 `body_accepted/body_quality` 支持和权重，不能把实验中的诊断10px门擅自替换为身体支持，也不能把身体支持解释为严格场景几何全部通过。

### 3.2 Stage、动态地面与助步器

场景调用 `--scene-profile mainline`，实际解析为 `baseline`。原识别器按背景运动与踝部证据判断 Stage 1、Stage 2、transition 和 warming_up。

Stage 1 保持相机/助步器相对地面的位姿，并保存合适的脚踝世界锚点。Stage 2 根据静态背景估计相机旋转，再利用严格踝观测和世界锚点估计平移：`t_i=A_i-R*p_i`。证据不足、左右旋转冲突、踝点缺失及恢复拒绝均保留状态，不伪造测量。

正式基线仍保留原恢复机制及其跳变风险。`landing_fixed_lag` 和 `joint_stage_window` 是显式离线候选：部分运动指标改善，但落地闭合未通过；联合窗口还未满足实时计算预算。不能因为画面更顺就替换正式场景基线。

身体先在左相机坐标下拟合。显示时用本次重放的 `T_G<-C_t` 将身体网格、模型侧关节点、观测点、相机和助步器放到同一地面坐标系。旧逐帧变换或旧网页顶点不能参与当前动态显示。

### 3.3 SMPL-H 身体冷启动及共享形状

当前身体使用完整 SMPL-H、同一 COCO observation regressor 和 VPoser。每帧有32维身体编码 `z`、根旋转和全身平移；全片只有一组10维共享 `beta`。VPoser 解码得到每帧63维身体轴角。

优化预算为 A30、B30、C300、D1 100、D2 100，D3为0：

| 阶段 | 主要优化量 | 作用 |
|---|---|---|
| A：身体基础 | 平移与 VPoser 编码 | 从冷启动建立基础观测贴合 |
| B：形状 | 同一组共享 beta | 调整全片一致的体型 |
| C：联合身体 | 共享 beta、根旋转、平移、编码 | 联合处理体型、位置与姿态的取舍 |
| D1/D2：局部手姿 | 共享手部 PCA 参数 | 使用 WiLoR 原生 MANO 局部姿态信息；身体参数冻结 |
| D3：进一步精修 | 未运行 | 当前为0步 |

“共享”指每帧前向使用同一个 beta 张量，不代表它从第一步开始就冻结。C阶段仍更新同一组共享 beta；D阶段冻结身体。不能说联合优化 beta 就变成逐帧独立体型。

身体主观测项是原质量加权三维平方残差，内部位置使用米；输出分析转换为毫米。默认姿态先验为 `0.02*mean(z²)`，形状先验为 `0.001*mean(beta²)`，根旋转锚定权重0.01。零是编码/形状分布的中心，不是“所有关节角度应该为零”。

当前360帧人工腕项关闭，身体二维重投影、身体时序、手脚接触项也关闭。WiLoR 在这里主要提供原生局部手姿，不能把它当已经认证的相机空间手部位置或抓握约束。

## 7. 三个最重要的量化结果

### 7.1 前臂残差不是主要由骨长解释

令 `m=(肘+腕)/2`、`d=腕-肘`，观测和模型分别标o、p，则：

`||肘p-肘o||²+||腕p-腕o||² = 2||mp-mo||² + 0.5(Lp-Lo)² + Lp*Lo*(1-cosθ)`。

新无腕 PMPose 的左臂中点/长度/方向占比67.11/10.63/22.27%，右臂68.01/18.51/13.48%。这是共同支持上无权端点平方残差总和的组成，不是原质量加权训练损失分解，更不是“68%的问题因某模块造成”。

全身平移解析剩余量很小，说明当前目标下的整体平移已经基本收敛。应研究肩肘姿态和部位之间的目标取舍；不能由此排除外参误差、Stage世界漂移或观测偏差。

### 7.2 冻结身体参数不等于冻结身体表面

直接局部轴角候选固定 beta、根旋转、平移、腿姿态和手指，只释放 native13/14锁骨、16/17肩、18/19肘，身体姿态索引为12/13/15/16/17/18。每轴分量限制±0.15rad，Adam100步、lr0.005、batch32。

旧/新臂均残差79.98→63.13、75.12→51.82mm，但新最大残差383.24→409.28mm。下半身 COCO 最大变化1.67/2.04mm，未通过原1mm保护；足底顶点约2mm、掌面最大约286mm。完整姿态形变和顶点回归仍会影响表面，检查必须落到真实网格。

表面惩罚版本使用权重100、软界足底/下半身0.8mm和掌面8mm；事后硬界仍1/1/10mm。两组下半身最大0.426/0.243mm、足底最大0.417/0.262mm、掌面最大8.195/8.178mm，通过位移保护。臂均残差只降到78.39/73.37mm，仍有216/194个臂端点恶化超过1mm。

局部候选使用直接轴角，已脱离原 VPoser 编码空间，属于独立方法候选，不能称重构后等价实现。保护门也是相对原结果的位移预算，不认证原结果正确或接触真实。

### 7.3 关闭姿态先验是明确的取舍

两次 PMPose 都从原冷初始化完整跑 A30/B30/C300/D100/D100，只改 `vposer_prior_weight=0`，保留 VPoser 解码器、形状先验、根锚定和原观测支持。

| 指标 | 旧448：原值 → 关闭 z 平方项 | 新360：原值 → 关闭 z 平方项 |
|---|---:|---:|
| 原质量加权身体 RMS，mm | 62.668 → 51.041 | 51.097 → 42.047 |
| 臂端点均残差，mm | 79.98 → 58.92 | 75.12 → 57.49 |
| 腿点均残差，mm | 74.32 → 55.37 | 54.13 → 42.82 |
| 腿二阶差分 P95，mm/frame² | 63.22 → 71.43 | 73.68 → 96.92 |
| latent 均方 | 0.0676 → 0.4996 | 0.0490 → 0.4520 |

足底相对原同帧顶点的最大位移，旧左/右162.5/169.9mm，新137.6/320.1mm；这些是变化量，不是脚离地高度、接触误差或三维真实误差。

二阶差分由左相机坐标中的 COCO 膝踝点计算，单位为毫米/帧²，不是实际时间加速度。它增加只能说明逐帧变化变大，不能把全部变化都认定为抖动；真实动作也贡献二阶差分。`mean(z²)` 是逐帧姿态分布先验，不是显式时序平滑。后续需要核查动作变化是否保留，而不是只降低这一统计量。

## 11. 下一阶段建议与验收顺序

### 第一阶段：单模型观测语义诊断

优先解决原始观测可信性，先做警报层，保持原点和原门不变。分别处理双腕重合、单视图整臂换边、稳定身份错误。用已有人工帧和完整两采集逐帧记录核查警报覆盖与误报，不能仅以两个典型帧证明全片有效。

成功标准应是更明确的可用/可疑/不可判定状态及可追溯原因，而不是“接受点更多”。只有已有人工与图像足以确定身份的槽位，才有修复验证依据；其他帧不得自动当真值交换。第0帧人工标签异常继续保留并单独解释。

### 第二阶段：在完整身体保护下优化上肢方向

先在旧/新无腕 PMPose 原对照内研究局部方向。保留足底、掌面、下半身和原观测支持的保护预算；除均值外，必须报告最大残差、恶化端点、姿态边界、二阶差分和实际运行成本。

现有表面惩罚候选说明小幅下降方向存在，但收益小且局部恶化仍多。研究目标应是更好的约束内方向，而非增加步数、扩大轴角盒或放宽位移门。新方法必须明确是否保留 VPoser 编码空间。

### 第三阶段：渐进先验与动作保留

完整关先验已经完成，不应重复当新成果。下一单变量应是明确的先验尺度/阶段策略，保持同一观测、初始化、掩码、预算和其他权重。每次同时看身体贴合、腕肘、腿变化、足底/掌面、运行时间。

对二阶差分增加应按现有时间戳和连续有效段核查，区分真实动作变化与不稳定跳变。不能为了低二阶差分直接平滑显示或压掉动作。

### 第四阶段：候选复核后才讨论主线替换

目前没有本轮候选满足“整体更好且适合替换”的证据。两采集内部均应通过预注册保护条件，完整保留失败帧，再判断是否推广。单模型几何警报的低成本不等于整套实时；SMPL-H 当前仍为离线求解。

固定轴/掌向补偿、统一微小外参修正、无保护局部轴角以及直接关闭先验都不应直接设为新默认。DA3只允许图像空间 ROI/遮挡诊断，不进入标定、关联、筛点、三角化或米制深度。
