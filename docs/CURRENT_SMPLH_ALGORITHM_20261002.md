## 1. 当前究竟在解决什么问题

输入是一段同步双鱼眼图像、每侧的人体二维关键点、相机标定、人工手腕参考和已有 WiLoR 手部结果。输出是每帧的 SMPL-H 人体网格、同一个人的全片共享体型、逐帧身体动作、两只手各自全片共享的局部手指姿态，以及用于显示的地面和助步器位置。

“冷启动”指身体体型和动作重新求解：不加载旧拟合的 beta、根方向、平移、身体姿态、手形或优化器状态。它不意味着重新标定相机、重新训练人体模型，也不意味着必须重新运行已经保存的二维检测和 WiLoR。

当前完成的是离线整段工程拟合。448 帧一起参与优化，并不是视频来一帧立即输出一帧的实时求解器。页面按 30 fps 播放也不是算法达到实时速度的证明。

## 3. 数据身份、帧号和坐标

### 3.1 448 帧如何对应

当前数据是左右各 448 张有序 PNG：`pair_0000.png` 至 `pair_0447.png`。以 `pair_id=0..447` 对应二维点、WiLoR、拟合结果和场景变换。

图像位于 `research_records/engineering_validation/V20260908_people0_1_2_pmpose_c3_chain/people_1/input_448pairs/` 的 `left_ccw90`、`right_cw90`。这批图片是选定的原始帧对，不能拿采集视频的前 448 帧按下标替代。当前比较沿用冻结 C3 人体框；一般检测流程的框生成不在本次冷启动中重做。

相机角色固定为 cam0=LEFT、cam1=RIGHT。采集端按物理 PnP 身份识别设备，不把 OpenCV 数字索引视为永久身份。运行记录中的旧字段名可能包含检测器名称，字段名本身不能证明实际输入来源，应读取完整路径。

### 3.2 从模型图片回到鱼眼原图

原始鱼眼图像为 1920×1080。为了让人体在模型输入中站直，左图逆时针转 90°、右图顺时针转 90°。模型导出的关键点已经恢复到转正整图像素；进入几何前还要逆旋转。

设模型输出转正图片中的点为 `(u,v)`：

```text
左目原图点 = (1919 - v, u)
右目原图点 = (v, 1079 - u)
```

图像旋转只改变像素位置，不交换人的左手与右手。先恢复整图裁剪/缩放，再逆旋转；不能对已在原图坐标的点重复操作。当前 raw_side() 明确只适配这批 1920×1080 数据，换分辨率时不能直接照抄常量。

### 3.3 四种空间不要混淆

| 空间 | 数据含义 | 单位 |
|---|---|---|
| 转正整图像素 | 二维模型的整图输出 | px |
| 原始鱼眼像素 | 与相机标定相配套的二维坐标 | px |
| 左相机坐标 | 三角化、身体求解和人工腕参考使用的空间 | 三角化存 mm；拟合用 m |
| 固定地面坐标 | 网格、助步器、相机的显示空间 | 网格用 m；变换平移文件用 mm |

助步器还有自己的局部坐标，用于定义杆件、扶手端点与安装位姿。所有加减和比较必须先确认坐标系、方向和单位。

## 4. 二维点如何变成三维观测

### 4.1 统一关键点语义

身体观察接口使用 COCO-17：鼻、左右眼、左右耳、左右肩、左右肘、左右腕、左右髋、左右膝、左右踝。每点有 `(u,v,confidence)`。适配器把不同模型输出映射到这个顺序，保留原始输出用于追溯。

这 17 个点是图像观察语义，不等于 SMPL-H 内部的骨骼关节编号。后面的身体损失会用网格回归出的 COCO 点与它们比较；人工腕参考则另外作用于内部腕关节 20/21。

### 4.2 标定三角化

标定提供两相机内参、鱼眼畸变、左右旋转 R01、平移 T01。将原始鱼眼像素通过鱼眼反畸变变为归一化坐标，再使用：

```text
P0 = [I | 0]
P1 = [R01 | T01]
X_h = triangulatePoints(P0, P1, normalized_left, normalized_right)
X = X_h[:3] / X_h[3]
```

T01 以 mm 提供，因此 X 也是 mm，处在左相机坐标系。右相机点为 `X1=R01 X+T01`。把 X、X1 分别经过鱼眼投影回两张原图，计算像素残差；同时检查有限值、原图边界、两侧正深度和射线几何。

三角化不是简单把两条射线“画到交点”。有噪声时它们通常不相交，数值求解给出一个折中位置，因此必须保留重投影误差和射线间隙。

### 4.3 三套接收口径必须分开

**A. 实时/场景严格链。** 使用 `pose_app/triangulation.py` 的人物关联与三角化。人物关联基于归一化坐标的极线几何代价，中位 Sampson 型距离不得超过 0.05，`max_matches=1`。逐点要求左右分数各自不低于 0.25，原图坐标合法、三维有限、两侧正深度、平均左右重投影误差不超过 10 px。失败原因写入输出。

**B. 身体拟合候选链。** `raw_side()` 从每帧选定人物的关键点读取，`raw_triangulate()` 保留原图内、有限、正深度、非平行射线的候选。它没有严格链的逐侧 0.25 硬门，也没有 10 px 重投影硬门。较差点通过下面的连续权重降低影响。这是当前离线工程候选路径，不能把它的接收数宣称为严格链接收数。

**C. 当前人体页面的显示门。** 查看器重新计算候选，使用 `sqrt(cL*cR)>=0.25` 加平均重投影≤10 px 标记显示接收点。它与 A 的“左右各自≥0.25”并不完全等价。例如 `(0.16,0.64)` 的几何均值为 0.32，但左分数没有达到 A 的门限。

这是本次逐源码核对发现的现存口径差异。页面“严格通过”不宜直接当作实时严格链计数；应以正式严格输出为准。本文如实记录，未为写文档修改算法或重新生成实验结果。后续宜单独修正显示标签/门的来源并验证，而不是静默改写既有结果。

### 4.4 身体连续权重的准确公式

当前 `raw_triangulate()` 为每个候选计算：

```text
q2d   = sqrt(max(cL,0) * max(cR,0))
qray  = exp(-ray_gap_mm / 30)
qrep  = exp(-(left_error_px + right_error_px) / 16)
qsync = 1
qdepth = 1（两侧正深度），否则 0
q = clip(q2d*qray*qrep*qsync*qdepth, 0, 1)
不满足候选几何条件时 q=0
```

其中射线间隙是两条标定射线的最近距离。`qsync=1` 表示此函数不重新估计时间错位，不应宣称它已按逐对时间差校正同步。q 是启发式质量权重，不是经过校准的三维误差概率。

原始三维点、各分量、接收掩码和拒绝原因都应保留。拟合前为张量运算把 NaN 填零，同时用有效掩码排除；零值不是补出的观测。当前拟合只调用旧工具中的 raw_side/raw_triangulate，不执行那个旧工具主函数里的 smooth_points()。

## 5. SMPL-H 中究竟有哪些未知量

可以把 SMPL-H 理解成带骨架的可变形人体：体型决定身体比例，关节旋转决定动作，根方向和平移决定整个人如何摆放。模型按体型变形、姿态修正和蒙皮生成 6890 个顶点，使用 13776 个真实三角面。

| 未知量 | 优化变量形状 | 含义 | 跨帧关系 |
|---|---|---|---|
| beta | 1×10 | 体型系数 | 448 帧共用一组 |
| root | 448×3 | 根关节轴角旋转 | 每帧一组 |
| transl | 448×3 | 左相机系平移，m | 每帧一组 |
| latent | 448×32 | VPoser 身体姿态编码 | 每帧一组 |
| 左手 PCA | 1×12 | 左手局部手指姿态编码 | 全片共享 |
| 右手 PCA | 1×12 | 右手局部手指姿态编码 | 全片共享 |

VPoser 把每帧 32 维 latent 解码为 21 个身体关节的轴角，共 63 个数。当前不会解码之后再把某些腿或腕旋转替换成独立自由变量。VPoser 网络和 SMPL-H 资产本身是固定模型，优化的是这些输入参数。

模型网格通过固定 `J_regressor_coco.npy`（17×6890）得到 `predicted_coco`。这是“模型这边的 COCO 观察点”，用于与三角化的 COCO 观察点对齐。内部 `smplh_joints` 则用于骨架语义、腕关节和参数审计，两者不能混用。

### 5.1 为什么 beta 更新仍然是共享 beta

第 k 次优化时，所有帧使用同一个 `beta^(k)`。下一次优化变成 `beta^(k+1)` 时，所有帧一起使用这组新值。代码中 `beta.expand(n,-1)` 是共享同一参数的扩展，并非创建 448 组独立可训练体型。

因此“共享”描述帧与帧之间是否相同，“冻结”描述优化器还允不允许更新，是两件事。当前 B/C 阶段更新共享 beta，D1/D2 冻结它；最终序列全程体型一致。旧路线也已有共享 beta，不能把“现在开始共享 beta”当作抖动改善的原因。

## 6. 从零初始化怎么做

1. beta 和 latent 全部为零。零 latent 经 VPoser 解码得到模型的先验姿态，不等于所有关节轴角都为零。
2. 从模板 COCO 左右肩、左右髋构造正交身体基底。肩方向定义横向；肩中点减髋中点定义向上方向，正交化后叉乘得到第三轴。
3. 用当前帧三角化的同名肩髋点构造观察基底。令 `R_init=B_observed B_template^T`，转换为轴角存入 root。
4. 先按 R_init 转动模板，再用“观察髋中点减旋转后模板髋中点”求 transl。必须先旋转再算平移，否则会把朝向和平移初始化配错。
5. 检查 448 帧肩髋基底都有效，并检查初始化身体 RMS≤300 mm。失败写审计后停止，不插值跨过失败帧。
6. 保存 `cold_initialization.npz` 和 `initialization_audit.json`，供后续确认没有读旧拟合参数。

代码虽包含单髋平移回退，但当前整段入口仍要求所有帧具备完整有效的肩髋基底；不能据此认为缺双肩/双髋的序列已经被该路线支持。

手部系数在 A/B/C 为零，对应外部 MANO 均值手姿；WiLoR 初始化值直到 D1 开始才注入，防止手部观测提前影响身体初始化和 beta 求解。

## 7. 人工腕参考从哪里来、怎样使用

原始人工标注抽取了 0、50、99、149、199、248、298、348、397、447 这 10 对图片。每个可见腕点先从转正像素逆变换回原始鱼眼像素。

`solve_multiframe_wrist_targets.py` 假设手腕相对助步器固定、相机刚性安装在助步器上，因此每只手拟合一个全片固定的左相机系三维位置。它将所有现有人工二维点联合回投，使用 `least_squares(loss='soft_l1', f_scale=5, max_nfev=300)`，从多个双目初值中取成功且代价最低的结果。单目可见的标注也进入共同三维点的投影残差，但不冒充完整双目对。

门要求至少 3 对通过几何检查的双目标注、所有共同重投影误差≤10 px、两侧正深度。当前左腕失败原因包括有效双目对不足和共同重投影超门；右腕共同重投影超门。两侧状态均为 rejected。

当前运行在已授权的诊断模式下读取 `diagnostic_wrist_left_camera_m`，保留拒绝状态：

```text
左腕目标 = [0.1996661,  0.1245758, 0.1929522] m
右腕目标 = [0.1343017, -0.2719623, 0.3904329] m
```

这些位置来自人工标注和标定，不来自旧人体 beta 或构造抓握。但“独立于旧人体参数”不代表“独立验证过的解剖腕真值”。人工可见腕中心与 SMPL-H 内部腕关节中心也可能存在语义差异。

在 A/B/C 中，对内部腕关节 20/21 使用：

```text
L_wrist = mean_{帧,左右手}( ||J_internal_wrist - reference||² )
```

单位 m²，权重 1。它让手腕倾向参考位置，允许与身体观察和先验折中。它没有规定腕朝向，也没有强制每帧误差为零，更没有保证手指包住扶手。没有 1 mm/5 mm 软界尺度、没有腕阈值外 hinge；这些属于旧精修实验。

## 8. 身体损失逐项展开

记第 t 帧、第 j 点的模型 COCO 点为 C_tj，三维候选为 X_tj，权重为 q_tj，有效掩码为 M_tj：

```text
L_body = sum(M*q*||C-X||²) / max(sum(M*q), 1e-6)
L_vposer = mean(latent²)
L_beta = mean(beta²)
L_root = mean((root-root_init)²)

A/B 的有效身体目标：L_body + L_wrist + 0.02 L_vposer + 0.001 L_beta
C 的有效身体目标：上述目标 + 0.01 L_root
```

冻结参数对应的正则项可能仍出现在日志总 loss 中，但不会产生该阶段参数更新。手 PCA 正则也写在总式里，身体阶段手参数冻结。

L_body 是全部有效帧/点的加权欧氏距离平方均值；权重总和归一化，并非每帧先等权平均。因此有效高权重点更多的帧可以贡献更多。它没有直接重投影二维点的优化项，也没有使用稳健三维 Huber；质量主要通过 q 调节。身体观测仍含二维检测的腕点，与额外人工腕参考同时存在，二者不一致时优化做折中。

L_root 实际是轴角向量分量差的平方均值，不是 SO(3) 测地距离，也不是相邻帧时间平滑项。它限制每帧根旋转偏离自身初始化过远。

毫米变米要在平方前完成。例如 20 mm 残差为 0.02 m，平方为 0.0004 m²。损失权重有单位/尺度依赖；不能只看权重数字大小或不同公式下的总 loss 判定哪种拟合更好。

| D2 | 100 | 左右共享手 PCA | 0.005 | 用较低学习率继续手姿求解 |

总计 560 次全序列参数更新。每一阶段重新建立 Adam，因此阶段间不继承 Adam 一阶/二阶动量。历史实现每次更新都进行VPoser/手PCA解码和SMPL-H前向。2026-10-13起，无空间手部目标且只优化手系数的阶段直接计算局部旋转/PCA目标；仅在原日志采样点无梯度计算网格诊断，最终完整解码。身体/接触/手二维有效阶段仍按需执行完整前向。清梯度、有限值检查、反向、Adam更新顺序及各段预算不变，详见第27节。

当前是固定预算优化，不是通过收敛证明选出的全局最优解。它没有旧固定抓握精修中的候选投影、约束感知方向、原保护门回退事务、可达性认证；代码普通 Adam 不保证每步 loss 单调下降。运行完成与几何成功是两项检查。

入口 `run_sapiens_cold_smplh.py` 的默认 joint-steps 仍是 30；当前两份完成结果显式使用 300。复现必须核对 `fit_command.json`，不能依赖默认值。`--contact-steps 100` 在无接触模式下只是 D2 的步数名称，不能据此声称接触优化已开启。

## 10. WiLoR 到共享手姿的详细处理

### 10.1 只取哪些信息

复用左右相机已有的 WiLoR JSONL，每行必须对应一个正确的 pair 帧号。使用候选手框、手侧标签、框置信度和 15 个父关节相对旋转矩阵。

不将 WiLoR 的单目相机平移、全局根朝向、MANO beta、局部三维关节点或模型投影二维点当作当前身体/手腕的米制观察。元数据验证可能检查这些字段是否合法，但检查不等于拿它们构造拟合损失。

### 10.2 怎样确认是哪只手

每相机、每帧、每个解剖手侧分别处理。用当前身体二维腕点与原图手检测框关联：腕点有限、原图内、分数≥0.25；计算腕点到框的最近距离；最近候选距离≤150 px；若次近候选距离与最近差小于 25 px，则记歧义并拒绝。

选定记录后验证原生旋转约定、关节顺序、SO(3) 合法性和框分数，框分数用作该局部姿态假设的权重。它不是每个指关节的置信度。所有拒绝记录保存在审计中。

同一 WiLoR 文件在两组身体二维输入下，可能选中不同候选。这次左相机有 753 个共同接受假设，一组多 1 个；右相机 736 个共同接受假设一致。不能仅凭文件路径相同声称有效手信息逐条完全一致。

### 10.3 左右手旋转约定

原生输出采用右手规范，即使左手图片在裁剪时镜像过，也要把局部坐标基一起转换。设 `M=diag(-1,1,1)`，左手旋转为 `R_left=M R_native M`。只乘一边会得到错误的旋转/反射。

代码检查 MANO 与 SMPL-H 手指链顺序、左右镜像基底、模型顶点/骨骼数等。这里的手指顺序是 index、middle、pinky、ring、thumb，不可按常见直觉重排。

### 10.4 PCA 初始化与旋转目标

每手 15 个局部旋转转为 45 维轴角。使用真实 MANO 均值和前 12 个 PCA 分量，通过伪逆编码；按分量范数归一化系数。解码公式：

```text
hand_axis_angle = hand_mean + (hand_coeff / component_scale) @ components
```

SMPL-H 层配置 `use_pca=False, flat_hand_mean=True`，由本脚本在外部解码并加均值，避免均值重复相加。全片共享初始化是在 PCA 空间按两视图/各帧框分数加权取得；它只是初值。优化仍保留所有有效视图的原始旋转目标，不先把左右视图旋转平均成一个伪真值。

这里的component_scale是PCA分量的行范数，不是训练样本的系数标准差；基底方向归一化不等于概率白化。系数平方惩罚是当前工程正则，不能据此宣称已建立校准的MANO姿态概率模型。共享手姿只计算一套15关节旋转，再与全部原帧/视图目标比较；逐帧手姿模式仍逐帧解码。

旋转损失为 `||R_pred-R_target||_F²/4 = 1-cos(angle)`，先对 15 关节求均值，再按帧/视图权重归一化；左右手再取均值。当前手部有效目标是：

```text
0.1 L_native_rotation
+ 0.001 [mean(left_coeff²)+mean(right_coeff²)]
```

D1/D2 身体和 beta 均冻结；共享的是手指相对父关节的旋转，手在相机/地面中的位置、方向仍随身体链变化。因而“固定手姿”不等于“手在空间中固定不动”。

当前左手有 436/448 帧原生覆盖，右手 448/448。左手缺失 59、190、194、248、249、250、251、258、259、408、409、410 帧。这些帧没有手部观测证据；网格仍有手，是共享模型给出的估计，不是插值生成了新观测。

注意：日志仍有“wrist_to_distal_fixed_weights”字样，但它对应二维手点权重。本次 hand-2d-weight=0，原生旋转项按 15 指关节平均；不能将该日志字样解释为当前原生旋转损失已做近端/远端加权。

## 12. 场景分支：Stage 和动态地面

同源原始图像和当前二维/严格三维点重新经过已有 scene 回放，生成当前 Stage 和逐帧地面变换。固定标定、静态地面参考、助步器实体结构可复用；旧动态 Stage、动态地面、旧逐帧助步器位姿不作为当前输入。

Stage 状态识别先在 480 像素工作宽度的图像上排除人体和相机附着结构候选，在背景 3×4 网格取角点，KLT 前后向跟踪，RANSAC 仿射估计背景运动。用 5 帧因果窗口综合位移、路径与方向，左右视图按“可靠一侧确认运动就保留运动证据”融合。

Stage 1 表示助步器/相机近似静止而人体相对运动；Stage 2 表示背景随相机运动、双踝经背景预测后近似静止。证据不足则 warming_up 或 transition。它们是工程运动状态，没有逐帧人工阶段真值。

Stage 2 旋转来自背景本质矩阵 recoverPose；退化时单位视线 Wahba/Kabsch 回退。两视图旋转转换到同一坐标系做一致性检查。平移依赖 Stage 1 保存的踝世界锚 A_i：

```text
t_i = A_i - R_current p_ankle_i
t = 两侧一致时的均值
```

两侧不一致时经过预测和步长门选择恢复或拒绝。脚锚是 COCO 踝，不是脚底表面。它用于估计相机位姿，不等于脚底已接触地面。

估计器保留 5 帧脚点因果中位数及接受更新的 0.45 增益；拒绝/保持状态显式输出。重新确认 Stage 1 时重锚高度、俯仰和横滚，保留累计平面内运动。细节与阈值见 CURRENT_STAGE_GROUND_PIPELINE.md；其中旧帧数/结果是历史证据，本次计数读各 scene_sources.json。

当前两个数据分支各自重放场景。因为身体拟合不含 scene 项，两组地面差异影响显示和脚高度，不直接改变身体优化。比较脚底时额外交换两套变换进行交叉检查。

### 13.3 地面变换与脚底高度

```text
P_ground = R_ground_from_left[t] P_left + translation_ground_mm[t]/1000
```

同帧人体顶点、模型 COCO 点、三维观察点、助步器节点、双相机光心使用同一变换。右相机光心在左相机系为 `-R01^T T01`。

脚底候选顶点集合只提供模型拓扑编号，不加载旧身体坐标。统计这些顶点的最低 z，负值表示在当前估计地面以下。它同时受人体、体型、地面、鞋与裸足模型差异等影响，不等于真实穿地测量。当前不将脚底吸附 z=0。

### 13.4 页面如何解释

页面使用当前网格真实三角面，核对帧号、输入路径、当前 scene、顶点数量和手审计来源。显示有限但被拒绝的观察点，保留失败原因。双栏页面只同步当前帧滑条，不插值或重做拟合。

“腕偏差”是每帧左右内部腕关节到人工参考的距离；“观测残差”页面为每帧候选点残差中位数，而 assessment 的身体 RMS 是全体有效点 RMS，两者并非同一统计量。“脚底高度”是当前帧最低候选脚底 z。

“腕参考未验证”实际包含原几何门已拒绝的状态，不能读成完全没有检查过。“接触未通过”在当前页面概括的是手部几何代理，不是完整手脚物理接触认证。

### 19.2 评价口径

下表身体RMS是对同一接受掩码的三维观测残差，不是独立三维误差。另记录相同基线质量权重下的身体RMS、原始鱼眼重投影、躯干/上肢/下肢分组。腕P95始终对同一诊断参考计算，即使该组关闭腕损失；它只能说明目标满足程度。参考没有升级为经认证物理真值。

腿相对加速度：取SMPL-H内部髋/膝/踝关节点，减去骨盆位置，再用三帧二阶差分乘30²，报告范数的RMS。同时保留速度、动作幅度、膝屈曲范围和逐帧变化。该值包含真实运动及噪声，降低不自动等于去除了抖动；不能以更静止替代动作保真。脚指标来自真实SMPL-H脚底候选表面顶点与同源地面变换，保留每帧最低高度和低于-5mm帧数。未获得可靠支撑标签，不把脚底速度解释为支撑期滑移。

手旋转误差始终对相同基线关联的WiLoR原生假设计算，包含683个左手、807个右手视图帧，不是手姿独立真值。逐帧手旋转变化采用SO(3)相邻旋转夹角。所有组另运行全帧手表面/助步器几何门，没有更改阈值。运行时间保留原值，包含拟合内部输入审计、检查点与导出；不含独立几何评估及导入。部分开发检查共享GPU资源，不能将本表时间当严格速度基准。

### 19.7 发现的实现错误、修复与历史一致性

关闭腕参考首次在C阶段第86步因非有限loss停止。诊断发现真正来源是已关闭的手二维/接触分支：未定义投影产生NaN，旧实现用projection.sum()*0或非有限残差乘0构造“零项”，NaN乘0仍然是NaN，从而污染原本有限的活动身体目标。保留的整理前original_fitter.py也有相同写法，所以是原实现遗留问题，不是这次拆分文件引入；首次失败不能作为“无腕目标不可拟合”的科研证据。

修复在losses.hand_observation_term中对关闭/身体阶段直接返回有限零项；未活动接触项用张量空切片求和构造可微零项，不读取非有限投影值。活动项的非有限检查、梯度检查和原失败门继续保留，不能将真正活动的NaN掩盖为0。首次失败保留在主目录sapiens2_no_wrist/FAILURE.json，详细诊断在outputs/ablation_nan_diagnostic_20261003；同预算重试单独位于G20261003_smplh_ablation_retry_v1/sapiens2_no_wrist，汇总results_after_fix.json明确记录first_attempt_failure。

1. 新Sapiens2第139帧右图是肩肘腕整条手臂左右语义反转；第74帧则是双腕落在同一只手附近。稳定的错边不会触发简单跳变门，双腕重合也不能通过交换标签修好。
2. 原腕62/41正是官方308点定义，映射核对全帧通过。不能靠换一个“手部腕点索引”解释所有偏差。
3. DLT换成现有鱼眼非线性求解能降低重投影目标，但前臂长度变化不一致，没有解决模型与观测冲突。

### 22.3 与研究方法的关系

[DARK](https://arxiv.org/abs/1910.06278)研究热图坐标表示/解码；本项目已有DARK与argmax诊断，不能把持续语义换边当亚像素解码问题。[Generalizable Human Pose Triangulation](https://arxiv.org/abs/2110.00280)讨论跨相机布置的三角化泛化，支持分别检验两采集，而非只在一个视角调参数；本轮未实现其随机学习方法。[SMPLify-X/VPoser](https://smpl-x.is.tue.mpg.de/)提供学习姿态先验；这里的消融只关latent平方惩罚，并未移除解码器。[Sapiens2官方实现](https://github.com/facebookresearch/sapiens2)提供308点定义，本轮复用原输出并逐帧核对，不新增模型推理。

下一研究优先级：先把语义冲突诊断与正常观测明确分开，再研究带腕/足底/动作保护的上肢与先验更新。不能把降残差、低计算成本或视觉更稳直接写成三维精度、真实支撑或临床有效性。

## 27. SMPL-H基线的方法结构分析与精简（2026-10-13）

### 27.1 范围与结论

本轮针对SMPL-H优化基线，Flow Matching目录、模型、训练协议和对照由另一聊天处理。用户随后要求“仅执行方法的优化，不用核对运行结果”，因此最终阶段只做源码修改、单元/静态检查和现有文档更新，没有继续拟合、训练、渲染或核对真实序列输出。当前工作是计算结构与方法表述的改进，不是新模型精度结论。

现有方法的合理核心应保留：一个SMPL-H人体解码器、固定VPoser身体先验、全片共享体型、原生MANO局部手姿、已标定原始鱼眼投影。主要冗余来自“所有阶段都运行整条计算链”，而非SMPL-H模型本身包含多余网络。无需另外加入时序网络、接触预测器或再造一套求解框架。

正式360帧reference25和近期448帧二维拟合是同一内核的两种数据目标，不是两个必须叠加的模型。前者以加权三角化位置作为身体观测；后者以原鱼眼二维Huber作为身体观测，三角化仍用于初始化及根方向锚。两套旧结果、权重、阶段门和选择身份均保留。

### 27.2 最小的参数与计算结构

令序列长度为N，身体未知量为共享beta（10维）以及每帧root（3维）、translation（3维）、VPoser latent（32维）。当前共享手姿每侧12维，总共38N+34个待优化标量；360帧为13714，448帧为17058。VPoser/WiLoR网络权重不在本求解器中训练；输出6890个顶点也不是优化6890个自由空间点。

结构应理解为：

```text
原鱼眼身体观测 + 标定
    → 三角化冷初始化
    → A：位置/姿态 → B：共享体型 → C：身体联合
                                                 ┐
WiLoR已审查的局部旋转 → D1/D2：局部手PCA目标        ├→ 同一SMPL-H解码 → 网格/COCO/手点
                                                 ┘
严格场景观测 → Stage/动态地面 → 同帧场景变换与诊断
```

A/B/C共享同一个模型和参数容器，只改变可更新参数；D1/D2共享同一手目标，只保留原学习率和Adam重置策略。身体观测中的COCO点必须由posed vertices回归，不能为减计算换成内部关节；场景严格掩码与身体拟合掩码也不能合并。默认地面与接触诊断不反向进入身体目标。

### 27.3 已实施：按有效目标决定是否需要完整网格

实现位于`pose_app/smplh_fitting/pipeline.py`与`stages.py`。仅当阶段至少为D1、可训练参数恰为lhand/rhand、手二维权重为0，且该阶段没有有效接触目标时，使用local_hand执行路径。判定依赖实际可训练参数及有效目标，不依赖“shared”标志或阶段名称猜测。因此逐帧手系数与手时间正则也可沿此路径；接触D2/D3或手二维开启时仍执行空间模型。D1即使提供了后续接触资源，只要当前接触尚未激活，也可只求局部手姿。

在该路径中，优化步不执行VPoser、全片SMPL-H蒙皮、COCO回归、身体/手鱼眼投影、骨长和腕位置诊断。原每10步及最终步的日志时刻仍以当前参数无梯度重算网格，保留诊断含义；最后用完整模型输出真实网格、内部关节、COCO点及手点。没有沿用先前阶段的网格或假造缺失诊断。

不能把身体诊断一次缓存到D结束：手部姿态修正及蒙皮可能改变表面回归的腕点，冻结身体参数不意味着所有COCO观察点都固定。当前保留诊断采样时刻的真实前向，避免为了减计算隐藏这一耦合。

A/B/C只在body_reprojection_weight>0时执行身体双目投影。手二维关闭时不执行四条手投影；开启时D阶段为有效目标，A/B/C仅在原日志点无梯度计算手二维诊断。骨长仅在有效骨先验阶段或原日志点计算；contact仅在实际激活阶段执行。body_fit_weights与参考骨长张量移到循环外创建。

`fit_summary.json/stage_schedule`记录objective_execution和model_evaluations，后者只计优化循环内的模型调用，不含初始化、最终解码及可选observer。此元数据不改变验收等级。没有新增CLI开关、优化器、网络、结果格式分支或第二套迭代循环。

### 27.4 已实施：共享旋转只解码一次，保留全部观测

令每手PCA系数为c、均值为mu、分量矩阵为C，s_i为C第i行的范数。现有解码保持：

    theta(c) = mu + (c / s) C
    R_k(c) = Rodrigues(theta_k(c)),  k = 1..15

手部观测目标保持：

    L_h(c) = sum_(t,v) w_(t,v) [ (1/15) sum_k ||R_k(c)-Rhat_(t,v,k)||_F^2 / 4 ]
             / max(sum_(t,v) w_(t,v), 1e-8)
    L_hand = lambda_mano (L_left + L_right)/2
             + lambda_pca [mean(c_left^2) + mean(c_right^2)]

当前共享手姿的时间项恒为0；逐帧模式另保留原受支持三帧二阶项。冻结VPoser/beta正则仍作为原日志总目标中的常数保留，不影响手部梯度。

原先先把1×45轴角展开为N×45，再重复计算N份相同Rodrigues。现在`rotation_pose_loss`接收1×45，共享旋转在变换后广播，与原N×views×15目标比较。每步两手旋转变换从30N个降为30个；残差比较仍保留全部帧、视角、权重和缺失状态，没有先平均旋转，也没有把两视图冲突压成一个伪真值。逐帧手姿保留N×45分支。这是公式层面的相同目标，浮点归约顺序不同可能有微小舍入差异，不承诺最终迭代逐位相同。

同时纠正原注释：s来自基底行范数，不是PCA样本系数的经验标准差；现有L2正则不是已白化、已校准的概率先验。变更只澄清统计含义，不修改系数尺度、先验权重或现有参数解释。

### 27.5 已实施：关闭的项不读取未定义几何

`body_reprojection_loss`和`body_temporal_loss`在关闭时返回独立零标量，不再使用body_loss.detach()*0。NaN乘0仍为NaN，旧写法会让纯诊断污染关闭的目标。新路径允许关闭的投影/COCO输入为None；测试同时覆盖NaN诊断不进入梯度。有效观测分支的非有限失败、相机后方拒绝、原掩码及失败记录保持。

阶段预算、学习率、D1/D2间Adam状态重置均保留。D1与D2在无接触时确实优化同一个数学目标，但直接拼成200步会改变Adam动量，属于求解策略变更；没有数值依据时不把这种合并包装成无代价精简。A/B/C的体型—姿态交替也不因名字相近而删除。

| 整段共享手姿 | 这是“局部手指姿态基本不变”的建模假设，不是从数据证明了固定抓握；它不约束手腕世界位置或手—扶手接触，且使用整段未来观测，不能称在线因果估计。 |
| 身体后再拟合手 | D阶段身体参数固定，但表面回归腕点可能改变。若未来要提高腕匹配，应先评估其影响，再考虑“手固定后的身体微调”；本轮只保留真实诊断，不新增循环耦合。 |
| 仅COCO17脚踝观测 | 无足尖、脚跟、足底方向的直接观测。仅靠踝点及VPoser无法认证足底触地；现有地面、扶手参考不能被自动升级为物理接触真值。 |
| 接触实验分支 | 接触D2/D3会释放身体变量，但当前身体2D/3D观测项在D关闭。根锚和姿态先验不能替代观测约束；重新使用该分支前须定义数据保持项/保护门，不能因接口存在便接回基线。 |
| 缺失帧与初始化 | 二维目标支持单侧点，不等于整个求解器支持单目缺口；目前每帧肩髋初始化basis仍必须可用。拒绝是当前能力边界，不以插值掩盖。 |
| 固定步数与泛化 | C300等是预算，不是收敛定理；连续360/448帧也不是360/448个独立样本。未来效果评价须不同采集或独立标注，不能由平滑或回投影自行认证。 |

结论是保留“共享体型 + 有限维身体先验 + 独立局部手目标”的基线核心，减少无效计算和错误统计解释。当前证据不支持增加复杂网络、盲目增强接触/时序项，或宣称已得到最优人体模型。

## 28. 置信度加权、旋转锚与接触保持项的实际修正（2026-10-13）

### 28.1 本轮决定与适用入口

第27节的上轮工作主要精简计算并保留原目标，因此列出的三个可实现缺陷没有被修复：reference25的置信度下限、自归一化消除绝对可靠程度、接触阶段释放身体却撤掉身体数据项。只记录这些问题不足以完成方法优化。本轮已在同一求解器中实施修正，通用入口body.fit_smplh_wilor_sequence及tools/run_smplh_reprojection_experiment.py默认使用--fit-policy reliability；--fit-policy legacy明确保留历史目标。不是另建网络或第二套优化器。

已保存的360 reference25和448二维/踝倍率2结果未重算，仍属于legacy方法的历史结果。current_mainline.json同时记录selected_result_fit_policy=legacy和新源码默认reliability，不把旧网格当成修正后的结果。cold_smplh_legacy30.json、cold_smplh_joint300.json、冻结标量记录明确固定legacy；run_sapiens_cold_smplh、run_smplh_ablations及check_mainline_regression读取未记录策略的历史argv时补legacy，显式策略优先。直接重放旧mainline_fit_args.json必须补--fit-policy legacy；新策略不能继续带--body-weighting reference/uniform/no_*。quality在reliability策略下只是兼容选项值，实际解析为下述权重，不再调用旧quality公式。

### 28.2 为什么原来的“有权重”还不够

旧reference权重为M(0.6+0.4c) max(h(s),1e-4)；原始分数为0且几何可三角化时仍可能得到0.6。旧3D及MANO目标使用sum(w*residual)/sum(w)：分数全部乘0.1，观测项对先验的相对影响不变。旧reprojection_only先分别按每台相机的置信度和归一化再平均，两个各自只有一个点的相机即使分数为1和0.1，也可能具有相同影响。历史手二维读取器还将缺失box score设为中性1，虽有说明，仍不适合作为新方法的可靠程度逻辑。

自归一化可用于“给定观测集合的相对加权均值”，本身不是数学错误；但本项目把该项与VPoser、体型、手PCA、根锚混合后，又希望分数表达绝对观测可靠程度，两种语义冲突。修正针对这个冲突，不声称所有加权均值都不正确。

### 28.3 修正后的身体权重和目标

设N为原始帧数，J=17，c_vtj为输入检测分数。原始像素必须有限、在对应鱼眼图像内且0<c<=1；零分、非有限及越界分数不升级或截断成可信观测，原输入和逐视图拒绝原因保留。二维支持独立按视图判断，不能要求一台相机缺失时删除另一台的观测。三维还必须通过原身体几何accepted门；新增body_fit_support只用于拟合，不修改body_accepted，更不能冒充严格场景三角化掩码。

三维需要两侧共同支持，采用保守的瓶颈分数：

    c_stereo = min(c_left, c_right)
    s = max(e_left / r_px, e_right / r_px, ray_gap / r_mm)
    g = 1 / (1 + max(s - 1, 0)^4)
    w_3D = M_3D * c_stereo * g
    L_3D = sum_(t,j) w_3D(t,j) ||X_model(t,j)-X_tri(t,j)||² / (N*J)

r_px=25px、r_mm=80mm沿用现有工程尺度；采用两视图较大重投影误差，避免均值掩盖一侧异常。分数及几何尾部均没有正下限；几何只衰减，不再把同源的ray与reprojection指数惩罚重复相乘。权重在拟合前由输入计算并固定，不随模型残差改变以回避难点。min和四次尾部是可解释的工程可靠程度规则，不是联合概率、逆协方差或统计最优性结论；小视差下的各向异性三维不确定性仍未被标量权重完整建模。

二维直接使用各视图的分数，不能先把两个相机各归一化成同等影响：

    H(z) = z²/2, z<=1; z-1/2, z>1
    L_2D = sum_(v,t,j) M_vtj * c_vtj * a_j *
           H(||pi_v(X_model(t,j))-u_vtj|| / scale_px) / (2*N*J)

a_j是任务优先级；脚踝倍率只属于a_j，不称置信度，也不进入分母。固定分母保留全部原始观测位置，包括不可用项的位置数，因此低分或缺失真正降低观测项相对先验的强度。没有删除帧，也没有补造像素；全帧无有效观测时明确停止。两个分支仍用posed vertices→COCO17→鱼眼投影，不改为内部关节近似。

reliability要求一个正身体数据项，禁止同时启用由同一像素得到的3D和源2D目标，以免把相关证据重复解释成独立似然。需要研究混合目标只能显式使用legacy，并单独解释其经验意义。人工腕等外部参考保持原显式开关和来源边界，不能因名称包含independent就升级为真值。

### 28.4 手部、根锚及观测诊断同步修正

原生MANO每手损失变为sum_(t,v) score_box * mean_k(||R_k-Rhat_tvk||²/4)/(N*2)，左右手仍取平均；共享手姿仍只计算一次Rodrigues，但保留所有帧、视图和缺失位置。box score只反映检测候选可靠程度，不是15个关节的概率。手二维同样使用固定N*21分母，保留原手指优先级及边界衰减作为独立工程因子；缺失/非法box score保留点和原因、权重置0。手时间项只跨有正观测权重的三帧支持，不因有限但零分的点恢复“有效观测”身份。

根锚改为旋转空间中的有界chordal代价：

    a_t = min_(j in shoulders,hips) w_3D(t,j)
    L_root = (1/N) sum_t a_t * ||R(root_t)-R(root_init_t)||_F² / 6

除以6使单位权重、接近零的小转角时与原轴角坐标MSE具有相近尺度；它不是所有轴角位置处的相同局部度量。等价轴角表示（包括相差2pi）不再产生虚假的大惩罚，使用sinc形式Rodrigues避免acos端点梯度。chordal在180度处有驻点，因此仍是初始化附近的软锚，不是任意大旋转全局收敛保证。a_t也随肩髋输入可靠程度下降，避免数据项降权后又通过等强的初始化锚把同一低分观测强行固定；该锚来自同源初始化，是正则项而非独立证据。

body_m继续记录条件加权RMS作为诊断，body_objective_m2单独记录实际数据目标；二维诊断也保留按有效分数归一化的像素均值，不能把它混成优化分母。新策略hand_l/r_px为跨视图条件加权RMS，无正权重时为null。root_anchor为所记录加权目标的平方根，不等于角度误差。

result.npz保留原body_quality/body_accepted/body_fit_weights，增加拟合支持、原始左右分数、拒绝原因，以及新策略的stereo_confidence、geometry_attenuation和root_anchor_reliability。fit_summary记录策略、公式语义、经验校准缺失状态和physical_evidence。无效点先从投影/差值运算中隔离，避免NaN乘0污染有效梯度；有效非有限值仍报错。

### 28.5 接触、固定抓握与脚底问题分别如何处理

reliability的D2/D3在有外部接触输入、释放root/transl/latent时继续保留所选择的身体数据项，使用与A/B/C相同的权重和归一化；已启用的腕参考和身体时间先验也保留。统一body_observation_stage判定贯穿几何前向、损失计算和总目标装配，避免只计算诊断却没有接入梯度。D1手阶段仍冻结身体，普通无接触D2仍只更新手，D3仍为0。接触输入四件套及原局部协议继续约束该实验分支，不自动接回正式结果。

共享PCA只表示局部手指姿态不随帧变化，不能推出手腕—扶手刚体变换恒定；COCO17只有脚踝，不能独立确定脚底朝向、触地或支撑。这两项不是给损失再加一项就能“证明”的。输出明确记录fixed_grasp和sole_contact未建立；需要固定抓握时必须有可审查的手—扶手相对位姿或接触标签，需要足接触时必须有对应足部观测/独立接触证据及同源地面。没有这些信息，本轮不制造标签或硬性压脚到地面。这是修正模型的可宣称能力，并非解决了缺失的物理测量。

本轮只检查方法实现，不跑360/448全片拟合、不比较网格结果、不重算主线或Flow Matching。首轮142项相关单元测试通过；随后新增根锚置信度和历史argv策略覆盖，只重跑受影响33项通过（含2个新用例）。检查目标包括零分/异常分数、弱视图影响、固定分母、缺失状态、MANO共享梯度、旋转等价表示及近零/近pi梯度、接触阶段身体数据梯度和旧配置复现；3条原NumPy兼容FutureWarning保留。Python静态检查和AST解析见AI_PROGRESS本轮记录，不作人体精度证据。

## 29. 整体求解一致性与初始化精简（2026-10-13）

用户进一步要求整体再改进后，继续沿初始化→身体→手→接触检查。只处理能由代码依赖或构造反例确认的问题，仍不跑真实序列、不增加网络或新的迭代阶段。

1. **共享手初值保留完整假设。** 原先将主值轴角编码的PCA系数线性平均，+179°/-179°两个近似相同旋转可能相消到0°；对称chordal目标在此还可能梯度抵消。reliability改为从所有有效帧/视图选择box score最高的完整15关节PCA假设，平分确定性取先出现项。没有逐关节拼接，也没有从未来结果挑选最优；后续手目标仍保留全部观测。legacy保留旧平均，逐帧模式保留各帧最佳视图和缺失零初值。最高box score也不是姿态真值，只作为避免分支相消的确定性起点，不宣称消除了所有局部极小值。
2. **初始化门与拟合可靠程度一致。** 原初始化的无权RMS会让一个几乎零权重的远处点否决整段，随后优化却几乎忽略它。reliability的初始化body_rms_mm改为sum(w*error²)/sum(w)的条件加权RMS；原无权值另存unweighted_body_rms_mm，四点肩髋basis及每帧原始支持门仍必须通过。此处是“受支持观测的几何尺度”检查而不是混合先验的优化目标，所以使用条件加权均值，不能用固定分母人为降低几何门。没有删除低分失败点、插值或自动放宽门值。
3. **同一无效身体腕点不再重新用于关联手。** reliability下WiLoR像素与native参数读取器都要求关联腕点在原像素边界内、分数0.25..1且有限。>1等已被身体支持逻辑拒绝的分数，不再绕过检查用于挑选手候选；legacy读法保留。
4. **时间项按关节支持。** 身体时间项原来要求三帧全部17点有效，鼻/耳缺失也会撤掉膝踝约束。新策略逐关节检查三帧支持，并要求这三帧的左右髋都有效，因为相对坐标依赖髋中点；分母固定为原始(N-2)*17位置数。缺失某关节只关闭相关项，任一髋缺失会关闭依赖该盆骨的项，不跨缺口，不恢复缺失观测。该项仍默认关闭，也没有增加平滑强度或新增时间模型。
5. **接触项内部也保留绝对可靠程度。** 第28节已恢复接触阶段的身体数据项；进一步把hand/foot contact labels的归约从sum(w*r)/sum(w)改为sum(w*r)/(N*2)，reliability标签限定[0,1]，任务强度另由surface_*_weight控制。显式whole-video静态手表面先验也乘相应hand_contact_weight，不能在零支持帧仍以满强度覆盖身体数据。没有独立测量时，这些标签仍是外部假设/工程标签而非物理认证；未提供接触资源则不激活。legacy表面及全片手先验保留旧归约。
6. **相同初始化模板只计算一次。** reliability下首个零latent/零beta/零root模板仅前向1帧，构造身体基与骨长；随后将同一身体姿态展开给原有N帧旋转模板前向。decode_body_pose根据输入batch维度检查输出。省去N份重复模板，不引入解析LBS近似或替换第二次模型解码。局部手目标精简和原Adam阶段重置继续保留。

新元数据记录shared_initialization、初始化门归约、body_temporal支持、contact归约及global_hand_prior_support；原gradient_audit明确标成A/C部分身体项，避免把它误称为完整目标分解。本轮没有声称源接触NPZ只凭帧数即可认证同源性；调用者仍须遵守当前接触协议和输入来源约束，接触分支不因此获得主线资格。

针对以上修改，只重跑受影响的SMPL-H组件与MANO两个测试文件，63项通过（含6新增）：pi分支完整初始化、无效身体腕关联拒绝、低权点的初始化门/单模板batch契约、逐关节时间梯度、接触整体分数同比梯度及[0,1]范围。与第28节的142项初轮和33项受影响检查分开记录，不将重复执行相加当测试覆盖数。随后只做改动文件静态检查和提交差异检查，没有新整片拟合、训练、渲染、结果报告或性能评价。

## 30. 现有方法完整实现说明（2026-10-13）

本节依据当前源码记录**离线整段SMPL-H参数拟合器**。`fit-policy=reliability`是通用CLI的新默认；第25节已保存的360帧reference25网格仍来自`legacy`。本节没有重新拟合这些网格，也不把源码修正当作新的实验结果。文中路径相对仓库根目录，代码模块默认位于`realtime_app/`。

### 30.1 方法在做什么，哪些部分保持固定

给定同步双鱼眼人体观测、固定相机标定和WiLoR手部结果，求解一段视频的共享体型、逐帧身体状态及双手局部姿态。优化变量经过固定的VPoser与SMPL-H解码器生成网格；再将模型关节点或投影与有效观测比较，使用Adam分阶段更新变量。这里没有训练新的神经网络，也没有Flow Matching的噪声、速度场或候选采样。

```text
左右人体JSON ──转回原始鱼眼像素── 每视图坐标、分数、有效状态
                     │                      │
                     ├──固定标定三角化───────┤
                     │  3D、回投误差、射线间距、拒绝原因
                     │                      │
                     └──肩髋刚体初始化       └──固定观测权重
                              │
共享 beta、逐帧 root / transl / VPoser latent、双手 MANO PCA
                              │
                  固定解码器 → 网格与关节点
                              │
             身体3D或身体2D + 手部信息 + 参数先验
                              │
               A → B → C → D1 → D2 → 可选D3
                              │
                   最终参数、网格、权重和状态

WiLoR JSONL → 人体腕关联 → 每相机的左/右手候选 → 局部旋转或辅助像素
外部接触资源（可选）→ 当前地面中的手掌/足底表面目标 → 接触D2/D3
```

相机内外参、COCO回归器、SMPL-H形状/姿态基与蒙皮权重、VPoser网络、MANO均值和PCA基均不随拟合更新。相机身份沿用标定的`cam0=LEFT`、`cam1=RIGHT`，不能用临时OpenCV设备索引替换。场景Stage/地面是独立链路；通常身体拟合只在cam0坐标中进行，只有显式接触分支使用场景变换。

### 30.3 输入数据、帧顺序、坐标和单位

记序列长度为`N`，身体关节数`J=17`，相机数`V=2`。

| 输入 | 内容与契约 |
|---|---|
| `--left-raw / --right-raw` | JSON的`images`记录；每项使用`keypoints[0]`，接受17×3或23×3，23通道只取前17个COCO点；三列为u、v、score |
| 帧编号 | 优先`image_id`，其次`frame_index`；左右帧集合必须相同，并且排序后为0..N−1；不会取交集静默删帧 |
| `--wilor-left / --wilor-right` | 分别表示左/右**相机**的JSONL；每个文件都可能含解剖学左手与右手，不能按文件名只读一只手 |
| `--calibration-dir` | 双鱼眼K、D、cam0到cam1的R与毫米制T及图像尺寸；拟合不优化标定 |
| `--regressor` | 从6890个posed vertices回归COCO17的固定矩阵 |
| `--smplh-model` | 真实SMPL-H模型资产，检查6890顶点及手关节/均值契约 |
| `--vposer-dir` | CLI解析层允许省略，但`run_fit`运行时必需；不会默默切换为自由63维身体轴角 |
| `--mano-left / --mano-right` | 对应手的均值与PCA基；native路径还核对canonical right MANO资产 |

人体检测是在转正后的图像上产生的。当前读取器沿用1920×1080原图约定：左侧`(x,y)=(1919−v,u)`，右侧`(x,y)=(v,1079−u)`；先逆转正，再做关联与鱼眼几何。这里的1920/1080是实现中的固定约定，不是自动适配任意分辨率；更换分辨率/旋转方式必须修改并核对读取约定，不能仅更换标定文件。

左右鱼眼点先去畸变到归一化成像平面，以`P0=[I|0]`、`P1=[R01|T01]`三角化。`X_cam1=R01 X_cam0+T01`。原始三角化、射线距离及标定平移使用**mm**；进入SMPL-H拟合后统一换为**m**，像素残差为**px**，轴角为**rad**。地面变换的平移也必须从mm换成m后与网格运算。

身体输入数组是`N×17×3`，三角化目标同形。三角化还返回左右回投误差、射线最近距离、深度、accepted和逐点原因。此读取器是身体软权候选路径，**不是严格场景三角化门**；`body_accepted`、`body_fit_support`与Stage/地面使用的严格掩码是不同变量，不能互相替换。二维模式仍使用三角化进行初始化和诊断，并非完全取消双目几何依赖。

### 30.4 参数、张量维度与解码

令`K`为每只手的PCA维度（默认12），`S=1`表示全片共享手姿，否则`S=N`。

| 代码变量 | 优化形状 | 含义 |
|---|---|---|
| `beta` | `1×10` | 全序列同一个人的体型，调用模型时展开到N帧 |
| `root` | `N×3` | 根全局旋转的轴角表示 |
| `transl` | `N×3` | cam0坐标中的全局平移，m |
| `latent` | `N×32` | 当前VPoser资产的身体潜变量，解码为`N×63`身体轴角 |
| `lhand / rhand` | 各`S×K` | 两只解剖手的局部PCA系数 |

32维对应当前VPoser资产；实现会检查解码的batch和身体维度。按此维度计算，总未知量为`38N+10+2SK`。共享12维双手时为`38N+34`，逐帧12维双手时为`62N+10`。这只是参数数量，不是每阶段都一起更新。

每只手独立使用均值`μ∈R^45`、PCA行基`C∈R^(K×45)`及行范数`s∈R^K`：

\[
\theta^{hand}=\mu+(c\oslash s)C.
\]

`s`用于基向量尺度归一，不是由当前视频估计的误差标准差。`c=0`得到MANO平均手姿，而不是45个零轴角。共享模式先解码一组局部手姿，再展开到N帧；它只固定手指相对父关节的旋转，不固定手腕位置、手腕朝向或手相对扶手的刚体变换。

VPoser将latent解码为21个身体关节的轴角；SMPL-H结合共享beta、身体与手姿，经固定形状/姿态修正、运动学与线性混合蒙皮得到`N×6890×3`网格。身体观测点使用`COCO17=regressor @ posed_vertices`，不是直接抽取内部骨架的17个关节。手21点来自内部腕/手指关节和5个指尖表面顶点，并重新排列到WiLoR/OpenPose顺序。输出内部`smplh_joints`可能含库附加点，不能仅凭SMPL-H运动学52关节就假定输出恰好52行。

### 30.5 身体可靠程度：从原始score到最终权重

新策略把三个概念分开：**是否可用**由mask决定，**该观测有多可信**由score与几何衰减决定，**任务强调程度**由外部λ或踝倍率决定。mask不是分数，λ也不是概率。

每视图二维支持要求坐标与分数有限、在原始图像范围内且`0<score≤1`。非法或缺失观测保留原始数据和原因；不把负数、超过1的数或NaN裁成有效高分。

三维支持`M_tj`还要求双目几何accepted、三角化有限、左右二维均有效，以及回投误差/射线间距有限非负。对支持点定义：

\[
c_{tj}=\min(c^L_{tj},c^R_{tj}),\qquad
q_{tj}=\max\left(\frac{e^L_{tj}}{25\,px},\frac{e^R_{tj}}{25\,px},\frac{g_{tj}}{80\,mm}\right),
\]
\[
a_{tj}=\frac{1}{1+\max(q_{tj}-1,0)^4},\qquad
w_{tj}=M_{tj}\,c_{tj}\,a_{tj}.
\]

25px/80mm分别由`body_reference_reprojection_px`和`body_reference_ray_gap_mm`配置。取较低视图分数，是因为三角化需要两侧共同支持；几何仅作进一步衰减。平台内不额外降权，超出后连续衰减，无正的置信度或尾权下限。实现采用稳定的倒数形式，避免极大severity直接四次方溢出。

这些权重在优化前从输入观测算好，进入损失时detach；不会根据当前模型拟合得好不好反过来提升观测分数。原`body_quality`仍保存历史几何质量作诊断，新策略实际用`body_fit_weights`。同一个几何问题也不再被多个指数因子连续相乘重复抑制。

**这是一套保留可靠程度的加权逻辑，还不是概率/逆协方差模型。** 检测score没有独立误差标签的经验校准；min规则、25px/80mm及四次尾属于明确的工程选择。小视差导致的三维方向性不确定度并未用完整协方差表示。不能将“分数0.8”解释为“80%概率误差小于某毫米阈值”。

### 30.6 身体数据项、归约与梯度含义

记模型COCO点为`X_tj(Θ)`，三角化目标为`Y_tj`。三维数据项为：

\[
L_{3D}=\frac{1}{NJ}\sum_{t,j}w_{tj}\|X_{tj}(\Theta)-Y_{tj}\|_2^2.
\]

单位为m²，分母固定为原始`N×17`位置数，不是有效点数或权重之和。无效槽不参与算术；实现先选择/隔离支持点，避免`NaN×0`污染梯度。零占位只用于内部安全计算，原始缺失观测和拒绝原因仍保存。

二维数据项直接比较原始鱼眼像素。设`π_v`为固定相机投影、`u_vtj`为观测、`σ_px`为像素尺度：

\[
H(x)=\begin{cases}\tfrac12x^2,&x\le1,\\x-\tfrac12,&x>1,\end{cases}\qquad
L_{2D}=\frac{1}{2NJ}\sum_{v,t,j}m_{vtj}c_{vtj}p_j
H\!\left(\frac{\|\pi_v(X_{tj})-u_{vtj}\|_2}{\sigma_{px}}\right).
\]

`p_j=1`，仅在指定踝倍率时COCO15/16改为该倍率；该参数必须配合`reprojection_only`，明确属于任务优先级。默认`σ_px=100`；历史448二维配方的25px不是通用默认。两个相机共同除以`2N17`，不会各自归一化后再等权平均。模型在有支持的相机点后方时直接失败，不以安全占位掩盖这些点。

相同残差与雅可比下，权重1和0.1对数据梯度的贡献比为10:1。若整段分数都乘0.1，数据梯度也乘0.1，先验强度不变；这正是低质量整段数据应减少对先验覆盖的逻辑。原来的`Σwr/Σw`会抵消这种整体下降。另一方面，固定分母使缺失更多时数据总强度下降，这是设计结果，不是将缺失点恢复成低误差。

新策略要求`body_3d_weight`与`body_reprojection_weight`**恰有一项为正**。同一双目像素及其三角化结果不是两份独立证据，因此不同时作为双正身体目标。`body_observation_mode=legacy`只是旧命名的普通数据模式，不等于`fit_policy=legacy`；前者与新的可靠程度策略可以同时存在。

`body_m`仍是`√(Σw‖X−Y‖²/Σw)`的条件加权诊断；`body_objective_m2`才是上述固定分母三维项。`body_2d_px`是按检测分数加权的原始像素距离均值，不含Huber和踝优先级。诊断数值不能直接相加还原总loss，更不能解释成独立三维精度。

### 30.7 冷启动和初始化拒绝门

1. beta、latent和双手PCA系数从零开始，不加载历史拟合参数或Adam状态。先用一帧零beta/零root/零transl、零latent解码出的身体姿态生成模板；初始化模板明确使用零45维手轴角，与后续PCA零系数对应的平均手姿不同。
2. 用模板及每帧三角化的肩5/6、髋11/12构造身体正交基：左向量来自左右肩差，上方向来自肩中点减髋中点，正交化后取叉积补第三轴。根旋转为`R_init=B_observed B_template^T`，再转轴角。
3. 将同一模板身体姿态展开到N帧，按各帧初始根旋转重新调用SMPL-H。平移为观测髋中点减去**这个旋转后模板**的髋中点，避免方向和平移引用不同模板状态。
4. 所有帧必须满足现有肩髋方向与支持门。函数虽保留单髋平移回退的来源记录，但不能据此声称缺失肩髋的序列已获准绕过总体初始化门。
5. 新策略以`√(Σw‖X_init−Y‖²/Σw)×1000`检查初始化几何尺度，默认阈值300mm；同时记录原无权RMS。非有限、无有效支持或超过门值则停止，不自动扩大阈值、插值或换旧结果。

初始化门检验的是有支持点上的几何误差，所以使用条件加权均值；如果也除原始位置数，整段极低分反而可能把错误初始化压到门下。它的目的与混合先验的拟合目标不同，不能机械统一分母。冷启动仍依赖观测、标定、预训练资产和初始身体方向，不等于不使用先验。

### 30.8 手部观测、旋转约定与初值

WiLoR的原生MANO路径使用15个局部手指旋转，忽略其全局root、translation和betas，不将WiLoR相机尺度或手部形状当作人体真值。读取器核对参数约定、父相对旋转和关节顺序；左手转换为`M R M`的双侧基变换，不能只做`M R`。候选需与对应人体腕关联，新策略要求关联腕有限、在边界内且分数0.25..1；异常身体腕不能绕到手分支继续使用。

同一相机可保留左右两只解剖手，两相机给每只手至多两份局部旋转假设。native权重`b_tvs`来自有效`detector_confidence`，缺失/非法分数不给正权重。没有有效native覆盖的手会被拒绝，具体候选选择及拒绝原因写入既有参数检查文件。

将旋转转为45维轴角后，以`(θ−μ) pinv(C) ⊙ s`编码PCA。共享模式选择所有有效帧/视图中box score最高的**完整假设**，分数相同取最先出现者；逐帧模式选择该帧最佳视图，缺失帧初值为零。这样避免对+179°/−179°主值轴角直接平均后相消；不意味着最高分候选就是真实手姿，也不消除非凸问题。

native初值直到进入D1才复制到手参数，A/B/C不受其改变；即使D1预算为0，这个阶段入口赋值仍发生，后续D2可使用该初值。所有有效假设继续参与手损失，不只拟合被选为初值的一帧。

对一只手，局部旋转项为：

\[
L_{MANO}^{s}=\frac{1}{2N}\sum_{t,v}b_{tvs}\frac{1}{15}
\sum_{k=1}^{15}\frac{\|R_{tsk}(\Theta)-\widehat R_{tvsk}\|_F^2}{4},
\quad L_{MANO}=\tfrac12(L_{MANO}^{left}+L_{MANO}^{right}).
\]

单关节`‖R−R̂‖²/4=1−cos(角差)`，是有界旋转弦距离，不是角度平方的精确测地距离。共享手仅计算一次预测旋转，然后广播给所有N×2观测；不会复制独立手参数。`b`是候选框分数，不是逐手指测量精度。

可选WiLoR二维项使用其模型投影21点，是辅助信息。每相机、每手权重为box score×边界因子×关节优先级：边界内1、外部保留点0.1，腕1，五指各沿近端到指尖为0.95/0.82/0.68/0.48；缺失或非法box score为0。这条辅助路径的边界处理不同于身体二维硬支持，不能统一描述为所有越界手点已删除。每个相机×手项除以`N×21`，**四项相加**，没有再除4；单位px²，不使用身体二维的Huber尺度。关闭`hand_2d_weight`后不计算其投影损失，不能把WiLoR投影称独立人工2D真值。

### 30.9 先验、时序项与总目标

参数正则为：

\[
L_\beta=\operatorname{mean}(\beta^2),\quad
L_z=\operatorname{mean}(z^2),\quad
L_{PCA}=\operatorname{mean}(c_L^2)+\operatorname{mean}(c_R^2).
\]

根锚使用同源初始化作为软正则。令`a_t`为该帧两肩两髋四个`body_fit_weights`的最小值：

\[
L_{root}=\frac1N\sum_t a_t\frac{\|R(r_t)-R(r_t^{init})\|_F^2}{6}.
\]

这是旋转空间弦距离；局部小角度下约为角差平方/3。sinc形式Rodrigues避免直接`acos`端点问题，但180°仍可能出现驻点。该项是同源方向保持，不是新增独立观测，不能证明根朝向已准确。

可选身体时间项对模型COCO相对髋中点的位置作二阶差分，以0.03m为Huber阈值。新策略要求对应关节连续三帧有`body_fit_support`，并要求三帧左右髋均支持；除以原始`(N−2)×17`槽数，不跨缺口。即使是二维数据目标，这一时间支持仍依赖三角化支持。该项默认关闭。

逐帧手模式的时间项对PCA系数作二阶差分，先在K维取平方均值，再对**有效三帧组**求均值，最后左右手平均；支持来自有效手像素或native假设。它目前只使用是否有效，不按连续box分数缩放，归约也不是固定全序列分母。共享手模式该项为零。身体/手部二阶差分均未除采样时间平方，不能直接当成m/s²或角加速度；换帧率时不能无条件复用同一λ。

骨长项比较当前内部骨架的10组长度与零beta模板长度，默认关闭，因为启用会把共享体型拉向模板。独立人工腕参考也是显式可选项，参考路径与正权重必须一起提供；当前360主线未启用。没有这些输入就没有相应信息来源。

每阶段总目标可写为：

\[
L=\lambda_{3D}L_{3D}+\lambda_{2D}L_{2D}
+\lambda_{MANO}L_{MANO}+\lambda_{hand2D}L_{hand2D}
+\lambda_\beta L_\beta+\lambda_z L_z+\lambda_{PCA}L_{PCA}
+\lambda_{root}L_{root}+\lambda_{timeB}L_{timeB}
+\lambda_{timeH}L_{timeH}+\lambda_{bone}L_{bone}
+\lambda_{wrist}L_{wrist}+L_{contact}.
\]

这个式子列出可用项，不代表每阶段全部激活；实际开关见下一节。各项量纲不同，λ同时承担数值尺度与偏好，不能只按λ大小比较约束强弱。改为固定分母后，旧λ尚未重新调优，不应标成统计最优配置。

### 30.11 可选接触分支的具体计算和边界

启用必须同时给出`contact_labels`、`scene_transforms`、`contact_vertex_sets`、`walker_topology`，且手/足表面总λ至少一项为正。读取器检查有限值、数组形状、旋转与顶点索引等；reliability下手/足标签在[0,1]，标签全零失败。几何形状检查不等于对采集同源性或物理标签真实性的独立认证，调用者仍须遵守当前实验协议。

cam0网格变到每帧地面：`V_G=R_GC V_C+t_GC`。手掌顶点计算到扶手线段胶囊表面的有符号残差`d=distance_to_segment−0.016m`；足底顶点使用`d=z_G`。它们都使用真实模型表面，不能用COCO腕/踝替代。

对K个候选表面点，中心化softmin和pseudo-Huber为：

\[
\operatorname{csoftmin}_\tau(d)=-\tau\log\left(\frac1K\sum_i e^{-d_i/\tau}\right),\quad
\rho_\delta(x)=\delta^2\left(\sqrt{1+(x/\delta)^2}-1\right),
\]
\[
\ell(d)=\rho_\delta(\operatorname{csoftmin}_\tau(d))
+\frac1K\sum_i\max(-d_i,0)^2.
\]

当前`τ=0.005m`，手`δ=0.015m`、足`δ=0.010m`，穿透项系数1。softmin减去了点数造成的偏移，是平滑的表面距离代理；不是要求所有候选顶点同时贴在平面，也不是精确的最小距离。

手、足分别按`Σ_(t,s) label_ts × ℓ_ts/(2N)`归约，再乘各自λ。显式全片手表面先验在固定相机—助步器变换下比较对应掌顶点，距离除0.03m后作Huber，顶点均值乘该帧手标签，再按帧和左右手平均；零标签帧不再接受满强度先验。

接触D2/D3释放身体变量，所以新策略同时保留原来选择的身体数据项，避免全身只为满足接触而漂移。接触标签、扶手尺寸和地面仍是外部输入/假设；共享手PCA不证明固定抓握，只有踝观测也不证明足底接触。未提供独立物理信息时，输出的`physical_evidence`明确保留未建立状态，不从拟合残差自动生成“真实接触”。

### 30.12 减少冗余计算的实际路径

当阶段≥D1、训练变量恰为双手PCA、`hand_2d_weight=0`且该阶段无接触目标时，native局部旋转、PCA先验和手时序已经能完整计算活动梯度。此时采用`local_hand`路径：普通优化步不调用全身SMPL-H，日志步才在`no_grad`下重算完整模型诊断。若手二维或接触依赖空间位置，则仍走完整网格路径，不近似替代蒙皮。

日志按全局步`step%10==0`或最后一个优化步记录。共享手的15组预测旋转只转换一次，观测仍保留全部帧/视图；固定手映射、置信度和关节优先级移到循环外。初始化的首个零状态模板只前向1帧；带各帧root的第二次模板前向仍为N帧。最终输出也始终用最终参数重新解码完整网格。

手指蒙皮可能改变表面回归的COCO腕，所以“身体参数冻结”不能推出所有COCO点完全不变；日志与最终输出重新计算这些点。`stage_schedule.model_evaluations`只计阶段循环中的模型调用，不包含初始化、最终解码或外部observer，不能直接当作整次运行总调用数/性能测试。

### 33.2 模型与必须挑战的假设

主要分析COCO左右肩/肘/腕/髋/膝/踝12点，不拟合手指或脚趾细节。保留根部、必要躯干和脚部刚体姿态以连接四肢及定义脚跟锚；脚跟不是COCO踝点，固定脚跟也不等于固定整只脚、证明承重或平衡。

一帧只能初始化位姿，不能测得速度。初始速度零是先验；若开头已运动，必须允许后续观测纠正，而不是把零速度强制延续。形状/骨长在第一帧或独立预采集校准后冻结。最近448结果的共享beta使用全片信息，只可用于明确标注的离线诊断；因果对照不能偷偷把它作为第一帧已知真值。

状态取广义位姿q（根平移、根SO(3)方向与局部关节旋转）和广义速度v，优化变量u是广义加速度。关节点由同一人体运动学链p_j(q,beta)生成，不独立驱动12个自由xyz点。局部离散近似为：

```text
q[k+1] = q[k] ⊕ (v[k] dt[k] + 0.5 u[k] dt[k]^2)
v[k+1] = v[k] + u[k] dt[k]
```

旋转采用SO(3)指数映射/切空间更新，速度的表达坐标与运输须一致，不能把任意轴角相加当成精确动力学。人体关节点的笛卡尔速度/加速度为J_j(q)v与J_j(q)u + dJ_j/dt v，不等于u本身。若只使用上述积分和幅度/变化率约束，结论是运动学跟踪；真实动力学还需要质量、惯量、关节力矩、重力、摩擦、接触力及浮动根动力学。浮动根不能被当作任意可控真实驱动。

双目残差使用左右原始鱼眼像素及各自有效性/可靠程度，世界人体点经逐帧world-to-camera与同源标定投影。2D观测与由其三角化得到的3D不得在同一目标中当两组独立测量重复计数。VPoser可作位姿先验，但不把其latent速度/加速度命名为关节角速度/角加速度。

MHE目标可写为L_2D(q)+lambda_pose L_pose(q)+lambda_u sum(||u_k||^2 dt_k)+lambda_du sum(||(u_k-u_{k-1})/dt_k||^2 dt_k)+L_arrival(q,v)，满足离散积分、关节范围及移动助步器阶段脚跟硬等式。加速度/变化率项按时间加权；不同帧率不能沿用未归一化逐帧惩罚。工程可靠程度不能直接冒充校准逆协方差，未来首次实验再在开发数据确定这些lambda。

用户明确选择“移动助步器阶段全部强制固定，作为假设对照”。因此区间S使用冻结的移动助步器阶段标签完整片段，第一轮可按当前stage2_feet_static_walker_moving定义（448基线共有115帧）；不能再筛成肉眼静止子集或删去冲突帧。每个连续片段开始重新建立a_L/a_R，在固定世界坐标全程硬约束h_L(q)=a_L、h_R(q)=a_R；离开区间立即释放，不能全片固定。Stage标签是实验输入假设，抬跟、滑动、转身或边界误分将体现为投影残差/不可行；显式保留，不静默改为软约束、缩短区间或松门。transition状态另保留，并明确当前标签未把它列入S；若另定移动阶段，其区间须在比较前冻结且各方法相同。

现有相机世界平移部分依赖脚锚。第一轮冻结同一场景轨迹只检验人体求解变化；不能用同源脚锚得到的相机轨迹，再以脚跟静止证明世界恢复正确。独立世界评估须使用独立视觉rig轨迹或外部参照。真实仿真人体依赖助步器手部支撑时，即使不研究手指，也需要腕部外力/接触边界；省略这些可能迫使RL改变姿态以维持无辅助平衡。

用户进一步提出由过去若干帧的二维位移，经双目得到相机相对三维加速度，再积分速度/位置，最后转换到地面。本节为具体设计意见；没有实现或运行新人体跟踪器。本轮实际完成的是场景ORB-SLAM3/cuVSLAM适配及比较，两个后端均未达独立世界轨迹门，详见场景说明2026-10-14实施节。相机相对跟踪可继续研究，世界运动学量暂不能由这些候选轨迹认证。

### 34.1 保留加速度状态，但必须有位置观测闭环

双目标定、左右关联和深度可观测方向充分时，当前左右二维位置提供米制位置约束；过去若干帧再提供速度/加速度信息。主链应同时估计p/v/a，以积分预测下一时刻，再用当前左右原始二维位置纠正全部状态；不先对抖动位置二阶差分得到a，再长期开环双积分。

对单关节点，候选A为相机相对常加速度EKF：x=[p_C,v_C,a_C]，其中v_C和a_C明确是时变相机坐标p_C(t)的导数，不是世界速度/加速度在相机轴上的简单表达。真实时间间隔下的状态转移为：

```text
p_pred = p + v*dt + 0.5*a*dt^2
v_pred = v + a*dt
a_pred = a
y_L = fisheye_left(p_pred)
y_R = fisheye_right(R_right_from_left*p_pred + t_right_from_left)
```

当帧像素创新经投影Jacobian更新p/v/a及其协方差；白噪声jerk过程项Q按dt缩放，不将未校准检测分数直接作为逆方差。零初速仅作先验，初始a可置零但给不确定度；相机运动会进入相对运动过程噪声。短缺失允许prediction_only，失效原因和不确定度增长保留；不能标成观测支持或无限外推。投影后的固定骨长修正必须同步处理v/a，否则滤波状态不一致。A用于低成本受控对照，不能称完整人体动力学。

直接由二维流求a还需要投影曲率项：ddot(y)=J_projection*a+[v^T H_projection_component v]，并不是二维二阶差分乘某个深度尺度。平行校正双目的Z=fB/d只作说明，二阶导数包含2fB*dot(d)^2/d^3-fB*ddot(d)/d^2；本项目必须使用完整双鱼眼标定，不能按平行双目公式代替几何。

独立位置噪声1cm、30Hz时，三点二阶差分噪声标准差约sqrt(6)*0.01/(1/30)^2=22m/s²；恒定加速度偏差0.05m/s²开环10秒造成0.5*0.05*10²=2.5m位置偏差。这些是解析示例，不能据此断言当前尖峰的实际来源。先差分再积分没有增加独立信息，持续位置反馈才阻止漂移累积。

### 34.2 移动相机下的位置、速度、加速度变换不同

令R(t)、c(t)为相机到固定世界的旋转及相机原点世界位置，且v_C=dot(p_C)、a_C=ddot(p_C)：

```text
p_W = R*p_C + c
v_W = R*v_C + dot(R)*p_C + dot(c)
a_W = R*a_C + 2*dot(R)*v_C + ddot(R)*p_C + ddot(c)
```

只在相机相对世界静止时，v/a才能简化为乘R。人世界静止而助步器相机加速，a_C非零而a_W=0，是直接反例。Stage标签和每帧R/c不会自动补齐导数；地面重锚、SLAM地图reset/优化跳变及不可用边界必须断段。初速度0也须注明参考系：人世界静止不意味着相机相对初速0。

不要直接对噪声VO位姿作二阶差分再叠加大补偿。候选B（首选人体版本）在每个窗口建立一个固定局部坐标快照F=C_k；F仅与当前相机瞬时重合，在窗口内保持不动。根据可信相机轨迹计算历史每帧T_Ci_from_F，直接拟合：

```text
p_j^F(t_i) = p_j,k^F + v_j,k^F*(t_i-t_k) + 0.5*a_j,k^F*(t_i-t_k)^2
pixel_L,i = fisheye_left(T_Ci_from_F * p_j^F(t_i))
pixel_R,i = fisheye_right(T_right_from_left * T_Ci_from_F * p_j^F(t_i))
```

对过去约0.5秒全部有效左右像素做鲁棒联合估计，二维位移的信息已经进入目标，不另造噪声二阶像素输入。换窗口时以同一物理状态的恒定坐标重新表达p'=S*p+d、v'=S*v、a'=S*a；它不是移动坐标的时间求导，所以没有dot(S)项。此v/a是固定空间轨迹在局部轴上的表达，不能命名“相对于正在移动的相机的导数”。只需要窗口内相机相对轨迹可靠，不必先完成全房间表面重建；但当前两后端不满足这一前提，不能用其跳变轨迹硬启用B的世界量。

### 34.3 从关节点最小验证进入人体运动学链

先以候选A或单点/自由点局部二次投影拟合验证时间、双目误差和短时遮挡恢复；每帧都反馈当前位置，不与纯二阶差分平滑混称。主要人体候选随后将自由p替换为冻结形状的SMPL-H运动学p_j(q)，状态含根/局部姿态与广义速度，加速度u驱动积分；像素残差是主数据项，驱动变化是弱先验，关节点笛卡尔加速度由J_j(q)u+dot(J_j)v产生。12点不能观测骨轴扭转，不能将所有估计角速度称解剖真值。

复用现有PyTorch投影、SMPL-H及历史窗口读入，不盲装大型因子图库。causal_skeleton_tracker目前只有位姿、按帧根预测/二阶位置项和COCO踝软静止；不是显式p/v/a或heel硬约束实现。skeleton_factor_graph的骨段世界方向也不等于父子局部关节链。先单独初始化第一帧/独立体型，不能拿全片共享beta或非因果temporal_body_prefit当因果输入。

比较A与人体B时固定检测、标定、时间、初值和相机轨迹来源；B再单变量比较无脚跟约束与完整移动助步器区间的双脚跟世界硬锚，延续用户选择，不筛静止子集、不静默放松。相机系位置可用而世界轨迹不可用时，分别标明world_velocity/world_acceleration unavailable；Stage辅助产生的量只能按该假设降级记录。最终输出p/v/a及坐标语义、观测/预测/失效状态，评价独立位置/速度/加速度误差与峰值/相位保存，不能单用“更小a”排名。先做状态估计器，再考虑网络学习未知运动项。

数学/实现参照：[Stone Soup常加速度状态模型](https://stonesoup.readthedocs.io/en/latest/stonesoup.models.transition.html#stonesoup.models.transition.linear.ConstantAcceleration)、[GTSAM固定窗示例](https://borglab.github.io/gtsam/fixedlagsmootherexample/)、[视觉投影Jacobian](https://petercorke.github.io/machinevision-toolbox-python/stubs/camera/CentralCamera/machinevisiontoolbox.Camera.CentralCamera.visjac_p.html)。本节变换及噪声例子是直接求导/计算，不来自外部系统本机性能。

## 36. 已实现：相机相对双目像素反馈 p/v/a 基线（2026-10-14）

本轮只实现第34节候选A，目标是验证“真实时间积分预测 + 当帧左右鱼眼像素纠正”的因果闭环。算法为 `realtime_app/pose_app/stereo_pva_tracker.py`，回放和曲线入口为 `realtime_app/tools/run_stereo_pva_baseline.py`，相关测试为 `realtime_app/tests/test_stereo_pva_tracker.py`。复用 NumPy、OpenCV 和现有鱼眼投影，不安装新滤波/优化框架。当前正式人体和场景选择不变。

### 36.1 输入、初始条件与坐标语义

- 数据为原 `people_1/input_448pairs` 的 `0..447`，同源左右 `c3_predictions/{left,right}/pmpose/raw_predictions.json`。只跟踪 COCO `5..16` 共12点：双肩、肘、腕、髋、膝、踝。腕/踝是肢段端点，不包含手指、脚跟或脚部姿态。左右输入各帧必须只有一个已关联人物、ID有序连续；本基线不另做人关联。
- `raw_side` 按 left_ccw90/right_cw90 的逆变换返回原始1920×1080像素。标定读取 `realtime_app/calibration/results`，右目点为 `p_R=R_cam0_to_cam1*p_L+T_cam0_to_cam1_mm`，使用完整旋转和毫米平移。
- 首帧单独重跑当前 SMPL-H 二维重投影方法，四份输入只保留 frame0；原448共享beta和逐帧拟合结果不进入初始化。沿用原reliability参数和A30/B30/C300/D100/D100/0预算、seed0，体型及局部手姿也只由首帧推断；12点从该单帧 `predicted_coco` 的米坐标转换为毫米。拟合自己的手部模块仅用于完成当前方法的初始化，不产生后续手部跟踪状态。
- `--initial-fit` 只接受 `pair_id=[0]`、`predicted_coco.shape=(1,17,3)`，拒绝完整序列拟合文件。首帧 `v=a=0` 为先验；不再用首帧像素更新一次，避免把已被初始化拟合使用的像素重复当成新证据。
- 时间来自 `selection_manifest.csv` 对齐采集 `stereo_pairs.csv` 的左右 frame_id 和 host_read_return_perf_counter_ns，整数纳秒先减原点，再取双目返回时间均值。严格递增，不以名义30FPS替换。

`p=p_C(t)` 是各时刻左相机系的位置，`v` 和 `a` 是该坐标信号的潜在一阶/二阶运动学状态。因此相机运动也进入这些量；这版**不需要假设助步器相机真的静止**。它既不是固定世界速度在相机轴上的表达，也不是力/关节力矩。离散输出位置还包含测量校正，`v/a` 不等于把输出位置数组直接差分得到的数值。所有帧输出 `coordinate_frame=current_left_camera` 和 `world_state_available=false`。此前草稿中 `left_camera_reference_assumed_static` 的命名不适用于这里的相机相对信号语义，最终版本已纠正。

### 36.2 预测、观测与纠正

每点独立维护9维状态和9×9协方差，顺序为 `[p_x,p_y,p_z,v_x,v_y,v_z,a_x,a_y,a_z]`。初始化协方差对角标准差为位置100mm、速度1000mm/s、加速度5000mm/s²。这是工程先验，尚未统计校准。

```text
F(dt) = [[I, dt*I, 0.5*dt²*I],
         [0,    I,       dt*I],
         [0,    0,          I]]
x_pred = F*x
P_pred = F*P*F^T + Q

Q = q * kron([[dt^5/20, dt^4/8, dt^3/6],
              [dt^4/8,  dt^3/3, dt^2/2],
              [dt^3/6,  dt^2/2,     dt]], I)
```

模型是 `da=sqrt(q)dW`，`q=1e8 mm²/s⁵`，表示允许加速度随时间变化；不是把全程加速度锁为常量，也不是已知控制输入。该白jerk的谱密度单位不能误写为某个 mm/s³ 标准差的平方。Q的时间组合性质已有测试，非均匀采样下不会把按帧二阶项当成物理加速度。

每次观测先检查：有限数、两视图原始边界、两侧分数均≥0.2且≤1、两射线夹角≥1°、双目三角化正深度、左右最坏回投≤25px。三角化仅做配对几何检查及失跟恢复初始化，**不会作为第二份3D位置测量更新已跟踪状态**。这些是本诊断基线自己的门，不能写成正式strict分支的accepted或物理正确性。拒绝原因逐点保留。

通过后直接构造4维像素观测 `[u_L,v_L,u_R,v_R]`，预测像素为当前p的左右鱼眼投影。投影位置Jacobian用±1mm中心差分；完整H为 `[J,0,0]`。统一像素 `R=4²*I`，检测分数只作门，不直接解释为概率或逆方差。

```text
innovation = observed_pixels - project(p_pred)
S = H*P_pred*H^T + R
NIS = innovation^T * solve(S, innovation)
K = P_pred*H^T*S^-1
x_candidate = x_pred + K*innovation
```

`NIS>64` 拒绝；该64是四维统计量的工程门，不能称经过校准的“8sigma事件概率”。K的p/v/a交叉协方差使像素残差同时纠正位置、速度和加速度；历史信息已经压缩在状态及协方差中，无须重复把二维差分作为独立测量。

本轮真实回放发现：大预测偏差/大协方差时，线性创新会允许一次错误更新，候选的**实际非线性鱼眼回投**可能仍达300–500px。最终版本追加一次真实投影：候选必须正深度、各视图≤25px且像素残差平方和不增加，否则记 `nonlinear_update_rejected` 或 `update_out_of_domain`，保留预测状态。成功后使用Joseph形式更新P并对称化；没有添加重复迭代、优化框架或显示平滑。

### 36.3 缺失、拒绝、失效与恢复

| 状态 | 含义 |
|---|---|
| initialized | 单帧SMPL-H初值，或从未有过轨迹的首次双目定位；零v/a是先验 |
| updated | 当帧双目像素被实际接受，且非线性候选通过 |
| predicted | 当前观测缺失/拒绝，仅按模型外推，P继续增长 |
| expired | 距最后初始化/像素更新超过0.5s，或预测离开正深度域；p/v/a及协方差输出null |
| reinitialized | 合格双目点建立新segment，v/a重置为0先验，P重置 |
| uninitialized | 尚无可用初始位置 |

无obs时不调用测量更新，也不无限外推。下一帧若已经跨过0.5s，即使重新看到像素也先断旧轨迹，再用当帧双目点恢复；不沿用旧速度/加速度。`segment_id`、`prediction_age_s`、具体reason和NIS逐点保存，失效不删帧。曲线在恢复/断段处留空，灰带表示仅预测；初值和恢复的零值不能解释成真实静止。缺一只相机时这版保守地只预测，单目降级更新尚未实现。

### 36.5 已暴露的问题、解决顺序与停止点

1. **人体形状没有持续约束。** 各点独立，首帧人体模型不能保证后续骨架。双方都updated时，右上臂端点距离范围147.75–266.03mm，右小腿321.53–569.37mm；COCO端点距离本身也不等于解剖骨长，但这些波动足以说明自由点模型缺乏人体一致性。下一步先将p由冻结形状的SMPL-H根/局部旋转生成，统一估计运动状态，不能仅裁剪p而不修正v/a及P。
2. **像素抖动、深度方向弱约束及初始收敛仍影响a。** 曲线有高频波动和缺观测时的常加速度平台；模长最大12.72m/s²不能被认定为实际人体峰值，也不能只靠减小它来排名。仅预测段速度P95达2.974m/s、最大7.261m/s：frame203左腕距最后更新0.4955s，继承前次大加速度外推，说明0.5s时限仍可能过长。0.5s历史拟合窗口与0.5s外推时限是不同参数；后续应在遮挡恢复试验中缩短预测时限或按位置不确定度停发，不能通过速度截断假造合理运动。先用重复静态采集/少量独立人工像素估计噪声，固定独立验证片段检验峰值和时滞，再调整R/Q。有骨架后可用约0.5s过去窗口联合投影拟合p/v/a；这是下一候选，本轮没有混入结果。
3. **大偏差线性化已修正，但仍会失跟。** 当前拒绝+0.5s超时恢复能避免接受严重候选，也会造成断段，特别是右膝。先核对这一点的原始两侧像素、遮挡/配对；若观测可信再考虑少量迭代EKF/短窗，不能放宽门或删除右膝来提高覆盖。
4. **运动相机和时间源限制。** 当前 v/a 含相机运动，返回时差/非均匀dt也可能混入伪高频。世界量要使用可信独立相机相对轨迹在固定窗口坐标中拟合，或按第34.2节完整求导；不直接对有跳变的VO做二阶差分。后续采集需要曝光时间/硬件同步信息，当前返回时间不能补成该信息。
5. **零初速、恢复与不确定度是先验。** 只有单帧无法识别真实初速/初加速度；重启后的导数会有暂态。应保留段边界和初始P，验证后再决定是否用前几帧因果短窗初始化速度。协方差目前未校准，不能从其大小给出真实覆盖概率。
6. **双脚跟约束的坐标前提未满足。** 本轮不加入Stage和脚跟；按用户已确定方案，后续人体版本仍应对移动助步器全阶段实施双heel世界硬锚，并与无heel版本做单变量对比。需要真实模型heel点及可信世界变换，COCO踝不能替代heel。不能把双脚踝锁在正在移动的相机系里。

本次停止点是这个独立基线的代码、448完整回放和问题定位已完成。可以作为人体运动学短窗/网络的因果对照；目前不足以替代正式人体主线或输出可信世界加速度，不增加RL、接触求解或新场景后端。

### 37.2 任务定义：RL控制一个估计器内的仿真人体

主方案为“双鱼眼二维观测 → 因果策略 → 关节PD目标 → 固定形状人体动力学 → 同源投影反馈”。目的不是控制真实设备，也不是让各COCO点独立接受任意加速度。人体内部状态为x=(q,v)，q含自由根与关节姿态；内部旋转按SO(3)/四元数积分，v为广义速度，形状/骨长在一次回放中固定。躯干和脚部刚体必须存在以连接四肢/定义heel，手指/脚趾细节不作为动作维度。

策略动作记作u_t=关节PD目标的局部旋转增量，区别于关节点线加速度a_j。限幅目标、力矩及关节活动范围，禁止为降低像素误差而每帧修改体型，禁止策略随意施加根部六维外力。动力学为：

```text
tau = clip(Kp * Log(R_joint^-1 R_target) - Kd * omega_joint, torque_limits)
M(q) * dv/dt + b(q,v) = S^T * tau + J_ground^T*f_ground + J_wrist^T*f_wrist + J_heel^T*lambda
p_j = observation_map(q, fixed_shape)
v_j = J_j(q)*v
a_j = J_j(q)*dv/dt + dJ_j/dt*v
```

质量/惯量/力矩界是明确记录的模型假设，不能从体型拟合声称已识别。仿真骨架关节中心不自动等于当前SMPL-H的COCO表面回归点：先固定解剖链与观测映射，检查多姿态映射误差。若刚体局部offset不能保持当前COCO定义，控制时刻调用相同SMPL-H/COCO解码；物理子步不重建6890顶点。拒绝用不同点定义的投影误差比较方法。SMPL皮肤回归点及刚体heel的导数要通过各自真实观测映射计算，不把PD角增量除以dt称为三维加速度。

采用“在线状态估计”时序：收到y_t后，从保存的x_(t-1)预测到t，策略读取该预测、y_<=t和dt，选择解释上一采样间隔的PD目标，再从保存状态积分该间隔得到x_t。该计算只用当前及历史观测，但它是到达观测后的状态估计，不声称实时物理执行器在间隔开始就知道y_t。若另做真实前向控制，则动作只能作用于下一间隔，单独评价预测时滞；两种时序不能混称。

### 37.3 观测、网络、奖励及缺失语义

第一版actor输入为：根局部重力方向、根/关节姿态与速度、上一动作；左右12点当前原始像素/模型预测/投影残差；逐点有效掩码、检测分数、距最近有效观测的时间；最近0.5秒历史与实际dt；相机标定/当前条件相机变换；冻结阶段状态及heel锚残差。不用原整段SMPL-H三维轨迹作为actor输入或伪真值。历史按时间截取而不是固定帧数；缺失用mask编码，0填充只用于张量占位，不能解释为像素(0,0)。不把检测分数、几何质量或RL value称校准概率。

两视图先各自编码再有序拼接；左右物理身份固定，不直接用平均特征丢失外参/单侧缺失信息。建议首版过去窗口浅TCN+MLP，MLP可从256/256开始，避免同时加入Transformer、AMP判别器和多教师。先使用同信息critic；以后若critic读合成真状态，必须记录为privileged训练，actor仍不得读取测试真值。原论文未来窗口仅作为后续离线对照，必须给经典方法同样的未来信息并记录延迟。

二维数据项和奖励提案：

```text
E_2d = sum_{camera,j} valid[c,j] * weight[c,j] * Huber((fisheye(T_CW*p_j)-y[c,j])/s_px)
       / sum_{camera,j} valid[c,j]*weight[c,j]
r_t = dt * [ w2d*exp(-E_2d)
             - we*sum(|tau*omega|)/power_scale
             - wdu*||u_t-u_(t-1)||^2/action_scale^2
             - wlimit*joint_limit_violation - wpenetration*penetration ]
```

先以二维项为主，其他项仅限制不合理控制，权重在训练集确定后冻结。未校准分数只作门/工程权重；踝点优先级如启用，对同组方法统一。没有有效像素时不计算归一化投影奖励，不因空集得到满奖励；控制正则可以继续，但观测失效状态必须显式保留。折扣按真实时间gamma(dt)=exp(-dt/tau_discount)，不让高采样密度区间无意得到更大总权重。

训练可用跌倒/数值失效早停提高采样效率；测试全448不删除跌倒区间，未输出槽位计入失败，恢复必须新segment并标记导数边界。训练优化总奖励，评价分别报告像素、失败、动作、接触和时滞，不把reward排名当精度排名。避免大加速度惩罚把真实运动峰值消掉，沿用现有失效/预测语义和独立峰值检验。

### 37.4 双脚跟全阶段硬固定与腕部支撑

保持用户已明确的“移动助步器阶段全程双heel固定”假设：每个连续Stage2片段入口由当前估计创建两个世界锚，片段内h_L(q)=anchor_L、h_R(q)=anchor_R，离开片段释放；transition单独记录，禁止事后缩成无冲突子段。heel不能替换为踝，固定一点也不等于weld整只脚。Stage状态如果由未来固定延迟产生，所有因果对照须共享实际发布延迟；可用冻结标签的离线条件实验不得称纯在线Stage预测。

[MuJoCo官方约束推导](https://mujoco.readthedocs.io/en/stable/computation/index.html#constraint-solver)明确普通约束模型是软的，R→0硬约束极限不允许。故不能仅设置connect或加脚滑奖励就声称硬固定。先以connect作数值基线，再实现明确的等式受限积分/状态投影版本；heel雅可比约束为J_h*v=0、J_h*dv/dt=-dJ_h/dt*v，位置和速度均须一致，不能只改脚点输出。位置约束投影后必须刷新动力学状态、记录校正量/等效冲量；存在普通地面接触时须检查耦合，不能盲目串接两个互相冲突的求解器。拟定数值门为每子步两heel位置残差≤1mm，超过则失败而不松约束。该门是工程近似误差门，不代表数学零残差。受限层未通过前仅报告软锚结果，不交付为硬锚路线。

这类世界锚允许人工约束反力，可能出现正常地面接触无法产生的拉力；必须记录反力/摩擦与法向冲突，不能借“零脚滑”证明承重、平衡或真实动力学。所有硬锚比较还需同动力学/同信息的经典受限控制器，避免把约束层收益归功RL。

腕部不研究手指仍会受到助步器支撑。第一版合成环境包含明确的walker刚体/把手几何及有界柔性腕支撑；真实版本只有确认的支撑区间才启用同一假设，并与无支撑版本分别报告。不能让策略凭空选择无限腕力、用根部悬挂防跌倒，或默认为全片刚性焊手；若支撑几何/区间不足，报告该模型边界，不声称已经证明物理可行。

### 37.5 数据、世界系与实际时间

### 37.7 评价目标与继续/停止标准

预先冻结独立人工二维验证片段，覆盖腕/膝/踝、遮挡恢复、运动峰值、Stage边界；当前所有448帧保留。分别统计两视图/各肢体人工像素误差、失败及恢复、预测持续时间、峰值幅度与相位、时延、heel约束冲突和腕力敏感性。同源检测回投另列内部一致性，强制零heel漂移只证明约束执行。末帧/首帧/重启的导数不补值；无支撑、无相机pose等状态分别报不可用。

合成held-out可计算世界p/v/a误差与相机相对误差，已知运动相位/峰值按相同噪声和时间对照；真实无独立三维真值不报告三维或加速度精度。动力学内部加速度与低频观测位置差分同时展示且标清来源，接触瞬间的高频峰不直接解释为人体生理加速度。

建议继续门为：比同信息经典人体跟踪，held-out人工二维平均误差下降≥10%，任何肢体组恶化不超过5%，失败比例不增加，峰值/相位不出现超过人工标注及同步不确定性的退化，硬锚通过1mm数值门；这些是待冻结的工程决策门，不是论文已经支持的效果。合成先检验相同控制器的p/v/a和遮挡恢复，避免仅低通平滑获胜。若独立标签不足则只完成工程候选，不通过精度门；两次修订后只有更平滑、误差无改善，停止该RL候选。成功也只能先成为隔离研究结果，独立场景/物理门通过前不得替换人体或世界主线。
